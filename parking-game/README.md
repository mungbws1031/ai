# parking-game — 주차 한 판

지갑 5만 원을 들고 하루 동안 여러 장소를 돌며 **직접 몰아서 세우는** 가로 화면 게임입니다. 노란 단속원이 길을 오가고 주민은 주황색 시야로 두리번거립니다. "잠깐은 괜찮겠지?"를 눈으로 판단하고, 볼일 보는 동안의 결과(신고·CCTV·딱지·견인)를 빨리 감기로 본 뒤 지갑에서 정산합니다.

`index.html`을 열면 바로 실행됩니다(빌드·서버 불필요). 공개 주소: https://mungbws1031.github.io/ai/parking-game/
설계: `docs/superpowers/specs/2026-11-24-parking-game-day-mode-design.md` · 계획: `docs/superpowers/plans/2026-11-24-parking-game-day-mode.md`

## 규칙

| 항목 | 값 |
|---|---|
| 시작 돈 | 50,000원 |
| 제한시간 안에 세움 / 늦음 | +10,000 / −5,000 |
| 자석 없이 칸에 반듯하게(정렬 80점 이상) | +3,000 |
| 세게 부딪힘(1.6m/s 초과) | −10,000 |
| 과태료 | 규칙표 금액(`rules.js`) |
| 사유지 경고 스티커 + 이동 호출 / 비매너 항의 쪽지 | −15,000 / −5,000 |
| 견인(첫 단속 10분 뒤, 30분 이상 머물 때) | −40,000 |

- **3일 진행:** 1일차(마트·아파트·쇼핑몰·주택가·병원) → 2일차(전통시장·지하철역·강 건너 휴게소·고속도로) → 3일차(단속원 2명, 제한시간 80%). 하루를 파산 없이 버티면 다음 날이 열리고 최고 기록이 저장됩니다.
- **매 판 무작위:** 빈칸, 주민 위치·시선, 머무는 시간, 단속원 위치.
- **눈에 보이는 단속:** 단속원 7m, 주민 시야 16m·70°(1분 간격으로 두 번 보면 신고), CCTV 반경. 숨은 주사위 없이 1분 단위로 계산(`day-sim.js`).
- **시간 규칙:** 시간제 허용 칸은 허용 시간이 끝난 뒤부터, 정차만 되는 곳은 5분 뒤부터 위반.
- **조작:** 조이스틱 하나(밀면 그 방향, 뒤로 당기면 후진) + 자석 주차(3.5m 안에서 멈추고 P).
- 법 설명은 정산 한 줄과 하루 끝 "오늘의 기록 → 근거 보기"에만 나옵니다.

## 예전 연습 모드

판단 퀴즈(네 가지 답으로 고르기)와 핸들·페달 직접 운전은 `classic.html`에 그대로 있습니다(첫 화면 아래 링크). 아래 내용은 그 모드의 설명입니다.

## 판단 연습 모드 (기본)

레벨 순서: **마트 주차장 → 아파트 단지 → 쇼핑몰 지하주차장 → 주택가 골목 → 병원 앞 → 전통시장 앞 → 지하철역 앞 → 강 건너 휴게소 길 → 고속도로 졸음쉼터 → 학교 앞** (+ 보너스: 카페 앞·학원 픽업·골목 맛집, 직접 운전 전용)

| 레벨 | 새로 배우는 것 |
|---|---|
| 마트 주차장 | 장애인·전기차 충전칸, 임산부칸(비매너), 매장 앞 보행통로, 통로 정차 |
| 아파트 단지 | 소방차 전용구역(소방기본법), 동 출입구 앞, 단지 소화전, 이중주차(기어 N) |
| 쇼핑몰 지하주차장 | 비상구 앞, 경사로, 여성우선칸(비매너) |
| 주택가 골목 | 거주자우선주차구역(지자체 조례), 남의 집 차고 앞(비매너), 골목 모퉁이 |
| 병원 앞 | 버스정류소, 승하차 점선, 구급차 진입로 |
| 전통시장 앞 | 시간제 주정차 허용 구간(허용 시간을 넘기면 위반), 화물 하역구역 |
| 지하철역 앞 | 택시 승차대, 역 앞 승하차 구역(정차만), 버스전용차로, 유료 노상주차 |
| 강 건너 휴게소 길 | 다리 위·공사구역 5m(제33조: 정차만), 맞은편 역방향 |
| 고속도로 졸음쉼터 | 갓길·비상주차대(제64조: 고장 때만), 졸음쉼터 |
| 학교 앞 | 어린이보호구역(정차도 금지, 과태료 3배) |

1. 상황 카드 — 예: "마트 도착, 장보기 30분 예정"
2. 지도의 번호 핀(후보 자리)을 누르고 네 답 중 하나를 고릅니다: **주차 OK / 정차만 / 안 돼요 / 법은 OK·비매너**
3. 차가 그 자리로 이동하고 정답과 쉬운 말 이유가 나옵니다. "그대로 두면?"으로 신고·CCTV·과태료(또는 관리실 조치·민원)를, "근거 보기"로 조문을 펼칩니다.
4. 다 풀면 상황이 바뀝니다(계산 줄이 길어짐 등 → 머무는 시간 증가). 실제로 둘 자리를 하나 고르면 결과 화면에 **다음엔 이렇게**가 먼저 나옵니다.
5. 같은 레벨을 **직접 운전**(핸들·페달) 모드로 다시 해 볼 수 있습니다. 제한시간은 기본 꺼짐(미리보기에서 켬).

사유지(마트·아파트)는 도로교통법 주정차 단속 대상이 아니므로, 소방기본법(소방차 전용구역)·친환경자동차법(충전구역)·장애인등편의법·관리규정·매너 기준을 함께 씁니다. 소화전·출입구 앞처럼 과태료는 없어도 위험한 자리는 "안 돼요"로 가르치고, 근거 보기에서 사유지라 과태료가 없다는 점을 밝힙니다.

## 한 판의 흐름

1. **이동** — 약속장소로 운전합니다. 건물 주차장은 만차입니다.
2. **잠깐 정차** — 근처에 세울 곳을 골라 멈추고 기어를 **P**로 두면 *정차 판정* 말풍선이 뜹니다.
3. **전화** — 받으면 상대가 늦는다고 알려 줍니다. 통화 동안의 단속 결과(신고·CCTV)가 굴려집니다.
   도착 후 20초 안에 멈추지 않으면 주행 중에 전화가 오고, 그대로 받으면 *운전 중 휴대전화 사용* 위반입니다.
4. **정식 주차** — 5분을 넘기면 법적으로 '주차'입니다. 통화 후 비는 구획이나 합법 가장자리에 다시 주차하고 P → *주차 판정*.
5. **결과** — 판정별 근거 조문, 과태료, 주민신고·CCTV·순찰·견인 확률과 실제 결과, 점수·별.

## 조작

| 입력 | 터치 | 키보드 |
|---|---|---|
| 핸들 | 왼쪽 아래 핸들을 돌리기(±450°, 더블탭 정렬) | ← → / A D |
| 가속 / 브레이크 | 오른쪽 아래 페달 누르고 있기 | ↑ / ↓ · Space |
| 기어 | P R N D 버튼(멈춘 상태에서만) | P R N F |
| 설명 말풍선 | 지도 아무 곳(구역·차·소화전·CCTV·시민) 탭 | — |
| 전체 지도 / 확대 | 상단 버튼 | M, + / − |

자동변속기 크리핑(브레이크를 떼면 천천히 움직임), 주행 중 핸들 복원, 중앙선(황색 복선) 침범·어린이보호구역 30km/h·보도 통행·접촉 사고를 감지합니다.

## 판정 로직

1. 차체의 9개 점(네 모서리·네 변 중점·중심)마다 걸친 구역을 모읍니다(`zones`, 빈 `slots`, `sidewalks`, 없으면 차로/주차장 통로).
2. 모든 점 중 **엄격도(severity)가 가장 큰 규칙**을 적용합니다 — 바퀴 하나만 소화전 5m 안에 들어가도 소화전 기준.
3. 가장자리 구역의 `dir`(통행 방향)과 차 방향이 90° 넘게 다르면 **역방향 정차**(제34조).
4. 정차 의도라도 5분을 넘기면 **주차**로 바뀝니다(제2조 제24·25호).
5. 구획 안에 9점이 모두 들어가면 각도·중심 오차로 정렬 점수를 매깁니다.
6. 불법이면 위험을 계산합니다: 주민신고(근처 시민 수·시간, 6대 신고 대상만), CCTV(반경·유예 시간), 순찰, 견인(운전자 부재·시간), 2시간 초과 가산.

## 반영한 규정 (승용차 기준 대표값)

- 정차·주차 금지: 교차로·횡단보도·보도(제32조 1호), 교차로 모퉁이 5m(2호), 버스정류소 10m(4호), 횡단보도 10m(5호), 소화전 5m(6호, 과태료 8만원), 어린이보호구역(8호, 2021.10.21~, 12만원)
- 노면표시: 황색 실선 정차·주차 금지, 황색 점선 5분 이내 정차만 허용, 백색 실선 정차·주차 가능
- 장애인전용 주차구역 10만원(장애인등편의법 제17조)
- 주민신고(안전신문고): 1분 이상 간격 사진 2장, 6대 대상(소화전·모퉁이·정류소·횡단보도·보호구역·인도)
- 견인(제35조), 운전 중 휴대전화(제49조), 중앙선 침범(제13조)

⚠ 게임용 단순화 모델입니다. 과태료·단속 방식은 지자체, 시간대, 탄력적 허용 구간, 법 개정에 따라 다릅니다. 확률 수치는 게임 밸런스용 추정치이며 실제 통계가 아닙니다. 실제 운전 시에는 현장 표지판과 [국가법령정보센터](https://www.law.go.kr)를 확인하세요.
