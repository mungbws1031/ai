# parking-game — 잠깐 세워도 될까

한국 도로교통법 기준으로 정차·주차 합법/불법을 판정하는 가로 화면 주차 게임 프로토타입입니다.
`index.html`을 브라우저로 열면 바로 실행됩니다(빌드·서버 불필요).

## 한 판의 흐름

1. **이동** — 약속장소로 운전합니다. 건물 주차장은 만차입니다.
2. **잠깐 정차** — 근처에 세울 곳을 골라 멈추고 기어를 **P**로 두면 *정차 판정* 말풍선이 뜹니다.
3. **전화** — 받으면 상대가 늦는다고 알려 줍니다. 통화 동안의 단속 결과(신고·CCTV)가 굴려집니다.
   도착 후 20초 안에 멈추지 않으면 주행 중에 전화가 오고, 그대로 받으면 *운전 중 휴대전화 사용* 위반입니다.
4. **정식 주차** — 5분을 넘기면 법적으로 '주차'입니다. 통화 후 비는 구획이나 합법 가장자리에 다시 주차하고 P → *주차 판정*.
5. **결과** — 판정별 근거 조문, 과태료, 주민신고·CCTV·순찰·견인 확률과 실제 결과, 점수·별.

## 조작

| 입력 | 터치 | 키보드 |
|---|---|---|
| 핸들 | 왼쪽 아래 핸들을 돌리기(±450°, 더블탭 정렬) | ← → / A D |
| 가속 / 브레이크 | 오른쪽 아래 페달 누르고 있기 | ↑ / ↓ · Space |
| 기어 | P R N D 버튼(멈춘 상태에서만) | P R N F |
| 설명 말풍선 | 지도 아무 곳(구역·차·소화전·CCTV·시민) 탭 | — |
| 전체 지도 / 확대 | 상단 버튼 | M, + / − |

자동변속기 크리핑(브레이크를 떼면 천천히 움직임), 주행 중 핸들 복원, 중앙선(황색 복선) 침범·어린이보호구역 30km/h·보도 통행·접촉 사고를 감지합니다.

| 파일 | 역할 |

| `levels.js` | 샘플 레벨 3개와 **입력 데이터 구조** 설명(파일 머리 주석) |

| `game.js` | 렌더링, 차량 물리(자전거 모델), 입력, 진행, 말풍선, 결과 |

## 판정 로직

1. 차체의 9개 점(네 모서리·네 변 중점·중심)마다 걸친 구역을 모읍니다(`zones`, 빈 `slots`, `sidewalks`, 없으면 차로/주차장 통로).
2. 모든 점 중 **엄격도(severity)가 가장 큰 규칙**을 적용합니다 — 바퀴 하나만 소화전 5m 안에 들어가도 소화전 기준.
3. 가장자리 구역의 `dir`(통행 방향)과 차 방향이 90° 넘게 다르면 **역방향 정차**(제34조).
4. 정차 의도라도 5분을 넘기면 **주차**로 바뀝니다(제2조 제24·25호).
5. 구획 안에 9점이 모두 들어가면 각도·중심 오차로 정렬 점수를 매깁니다.
6. 불법이면 위험을 계산합니다: 주민신고(근처 시민 수·시간, 6대 신고 대상만), CCTV(반경·유예 시간), 순찰, 견인(운전자 부재·시간), 2시간 초과 가산.

## 반영한 규정 (승용차 기준 대표값)

- 정차·주차 금지: 교차로·횡단보도·보도(제32조 1호), 교차로 모퉁이 5m(2호), 버스정류소 10m(4호), 횡단보도 10m(5호), 소화전 5m(6호, 과태료 8만원), 어린이보호구역(8호, 2021.10.21~, 12만원)
- 노면표시: 황색 실선 정차·주차 금지, 황색 점선 5분 이내 정차만 허용, 백색 실선 정차·주차 가능
- 장애인전용 주차구역 10만원(장애인등편의법 제17조)
- 주민신고(안전신문고): 1분 이상 간격 사진 2장, 6대 대상(소화전·모퉁이·정류소·횡단보도·보호구역·인도)
- 견인(제35조), 운전 중 휴대전화(제49조), 중앙선 침범(제13조)

⚠ 게임용 단순화 모델입니다. 과태료·단속 방식은 지자체, 시간대, 탄력적 허용 구간, 법 개정에 따라 다릅니다. 확률 수치는 게임 밸런스용 추정치이며 실제 통계가 아닙니다. 실제 운전 시에는 현장 표지판과 [국가법령정보센터](https://www.law.go.kr)를 확인하세요.
