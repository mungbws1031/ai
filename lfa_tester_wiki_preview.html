LFA 테스터스틱 전문 위키

슈얼리 오브제(Surearly Objet)의 소변 딥핑(dipping) 테스터스틱에 대한 정의 · 요구사항 · 설계 컨셉 · 평가 · 제조 · 리스크를 한곳에 모은 단일 지식 베이스(Single Source of Truth)입니다. 새로 합류한 협업 팀도 이 페이지부터 읽으면 전체 그림을 파악할 수 있도록 구성했습니다.

📖 이 위키는 무엇인가요?

테스터스틱은 사용자가 소변 컵에 담갔다(dip) 꺼내 리더기에 삽입하면, LFA(측면유동분석, Lateral Flow Assay) 스트립으로 정량(약 120 µL)의 시료를 전달하는 납작한 사출성형 부품입니다. 이 위키는 여러 문서에 흩어져 있던 설계 지식을 다음 관점으로 정리합니다.

  • 무엇을(What): 제품 정의와 고정 제약(치수·부피)
  • 왜(Why): 사용 맥락·인체공학에서 도출된 요구사항
  • 어떻게(How): 설계 컨셉과 정량·누수·전달 메커니즘
  • 무엇을 선택(Decision): 평가 스코어카드와 추천 컨셉
  • 검증(Validation): 제조성 · 벤치 테스트 · 리스크(FMEA)

01 · 제품 정의 & 핵심 사양

1. 제품 의도 (Product Intent)

컵에 담근 소변을 리더기로 옮겨 안정적으로 LFA를 구동하는, 납작한 사출성형 소변 채취 스틱을 설계한다. 사용자는 스틱을 컵에 딥핑 → 리더기로 이동 → 삽입하여 어세이를 시작한다.

2. 고정 제약 (Fixed Constraints)

파라미터값
단면 폼팩터납작(flat)
최대 두께5.5 mm
폭(width)17.89 mm
채취 방식컵에 사용자 딥핑
정량 목표어세이로 전달되는 순(net) 시료 ~120 µL
운반삽입 전 이동 가능해야 함
전달삽입 후 LFA 스트립으로 안정적 전달

3. 설계 성공 기준 (Success Criteria)

  1. ~120 µL 정량 재현성
  2. 낮은 사용자 부담(적은 단계, 직관적 신호)
  3. 운반 중 낮은 누수/드립 위험
  4. 견고한 LFA 스트립 적심 프로파일(볼러스 쇼크 최소화)
  5. 사출성형 + 실용적 조립을 통한 양산성

4. 본 위키의 컨셉 전개 프레임

각 컨셉은 다음 관점으로 전개한다.

  • 내부 단면 구조 · 모세관 유로 · ~120 µL 저장부 부피 · 소변–LFA 상호작용 · 사용자 핸들링 · 누수 방지 · 성형·조립 타당성
ℹ️

치수·부피는 EVT 초기 추정치이며 DFM·CFD·몰드플로우로 최적화 대상입니다.

02 · 요구사항 & 사용자 인사이트

사용 맥락에서 관찰된 사용자 행동을 엔지니어링 요구사항으로 번역한 결과입니다.

1. 관찰된 사용자 행동 리스크 (가정·근거리 환경)

  • 일관되지 않은 딥핑 깊이·시간
  • 기울어진 딥핑, 부분 침수
  • 딥핑 직후 즉시 이동(리더기로 걸어감)
  • "준비됨(ready)" 상태에 대한 불확실성
  • 가끔 과도한 딥핑·재딥핑

2. UX에서 도출된 요구사항

  • 채취는 방향·타이밍 변동에 관대해야 함
  • "채워짐(filled)" 상태가 명확해야 함 (시각/촉각/시스템 안내)
  • 제거 후 팁에 고인 액체 노출이 없어야 함
  • 가능한 한 수동(passive) 동작 우선 — 능동 단계가 있다면 명확하고 이진적(binary)이어야 함

3. 인간공학 가이드 (컨셉 #6–#9 적용)

  • 명확한 딥핑 라인·방향 표시 제공
  • 리더기 삽입력·경로를 결정적으로 (single hard stop)
  • 사용자가 부피·시간을 정밀 추정할 필요 없게
  • 가능하면 어세이 타이밍을 사용자 운반 타이밍과 분리

4. 기하 설계에 직접 영향을 주는 요구사항

요구사항설계 반영
딥핑 깊이 변동 허용명확한 딥핑 마커 + 모세관 정지(capillary stop) 기하
운반 중 누수 0밀폐 챔버 + 좁은 목 + (옵션) 기계적 차단
과/저충전 방지고정 정량 챔버 + 오버플로우/벤트 경로
볼러스 쇼크 최소화전달 목(neck) 유동 저항 튜닝
📚

사용 맥락·인체공학·유체 관련 원시 인사이트(수백 건)는 워크스페이스의 테스터스틱 페이지에 정리되어 있습니다. 본 위키는 그 인사이트를 설계 요구사항으로 압축한 것이며, 원본 링크는 08 페이지에 있습니다.

05 · 제조성 & 검증 계획

1. 사출성형 타당성 (컨셉별 요약)

  • #6 콤: 2-쉘 몰드 강한 타당성. 콤 미세형상은 경화 인서트 툴링, 밀폐는 초음파 웰드 권장.
  • #7 사이펀: 분할 채널 아키텍처로 가능. 크레스트/브레이크 형상 공차가 #6보다 타이트.
  • #8 링: 평면 대칭 채널로 매우 몰드 친화적. 방사 대칭으로 재현성↑, 고속 조립·초음파 밀폐 호환.
  • #9 슬라이딩 게이트: 가능하나 #6–#9 중 최고 복잡도. 슬라이딩 마찰·실 신뢰성 공차 필요, PP+POM 소재쌍 권장.

2. 검증 계획 (Validation Plan)

2.1 벤치 정량 테스트

  • 중량식(gravimetric) 충전 검증 (n ≥ 60/변형) @ 15 / 25 / 35 °C
  • 딥핑 깊이·시간 DOE: 얕음/표준/깊음 × 짧음/표준/긺
  • 수용 기준 시작점: 평균 120 µL ± 10 µL, CV ≤ 8% (어세이 요구로 튜닝)

2.2 운반/누수 테스트

  • 60초 보행 모션 프로파일 캐리 시뮬레이션
  • 충전 후 흔들기·전도(inversion) 챌린지
  • 팁·바디 외부 드롭릿 스코어링

2.3 LFA 전달/어세이 커플링 테스트

  • 고정 삽입력에서 스트립 적심 프론트 도달 시간
  • 채취 부피 산포 대비 밴드 강도 재현성
  • 과충전/저충전 조건 대비 invalid 비율 매핑

2.4 제조 검증

  • 핵심 미세형상 몰드 능력 연구 (채널 폭/높이 Cpk)
  • 웰드 무결성 버스트/리크 테스트
  • #9 슬라이더 내구 사이클 테스트

3. 권장 프로토타입 순서

  1. EVT: #6 · #8 수동 컨셉 우선 (속도·저복잡도)
  2. 병행 리스크 프로토타입: #9 누수 제어 트랙
  3. DVT 수렴: 누수 + 어세이 재현성 결과 기반

06 · 리스크 분석 (FMEA)

1. 컨셉별 상위 리스크 (FMEA 스타일)

#6 모세관 콤

  • 리스크: 이물/버블에 의한 타인(tine) 막힘
  • 영향: 저충전 변동
  • 완화: 매니폴드 목 확대, 타인 수 중복, 필터 립

#7 사이펀

  • 리스크: 낮은 딥핑 깊이에서 불일치 프라이밍
  • 영향: 무충전/지연 충전 이벤트
  • 완화: 명확한 딥핑 깊이 마크, 크레스트 형상 튜닝, 프라이밍 인디케이터

#8 링

  • 리스크: 외주(perimeter) 오염 / 부분 링 막힘
  • 영향: 비대칭·느린 충전
  • 완화: 다중 방사 피더 + 큰 링 유압 중복

#9 슬라이딩 게이트

  • 리스크: 사용자 잠금 누락 / 오결합
  • 영향: 운반 중 누수
  • 완화: 고대비 잠금 상태, 청각 클릭 디텐트, 잠금 상태 확인 리더기 인터록

2. 공통 제조 리스크

  • 미세채널 플래시/버 → 모세관 압력 변화
  • 로트 간 표면에너지 드리프트 → 적심(wetting) 변화
  • 웰드 편차 → 내부 누수 경로 생성

3. 공통 완화 제어

  • 미세형상 무결성 인라인 머신 비전
  • 표면 처리 공정 관리 + 주기적 접촉각(contact-angle) QA
  • 침수/압력차 100% 리크 테스트 (실용 범위)
🔁

본 표는 설계 단계 위험 식별용입니다. 정식 위험관리(ISO 14971)와 사용성 위험(IEC 62366) 연계는 규제 워크플로우에서 별도 관리하세요.
