# 합주실 (jam/)

코드를 들려주면 베이스·키보드·기타·드럼이 어울리게 반주해 주는 단일 HTML 웹앱. 서버도 빌드도 필요 없어요. `index.html`을 브라우저로 열면 돼요. 마이크는 https나 localhost에서만 켜져요.

## 코드 넣는 법 세 가지
- **직접 적기**: `C G Am F`처럼 한 칸에 한 마디. `C,G`는 한 마디에 코드 두 개, `%`는 앞 마디 반복. maj7, m7, 7, m7b5, dim, aug, sus2/4, 6, 9, add9, 분수 코드(`G/B`)를 읽어요.
- **마이크로 연주하기**: 템포와 마디 수를 고르면 한 마디 카운트인 뒤 딸깍 소리에 맞춰 들어요. 박마다 크로마를 모으고 비터비로 코드 바뀜을 매끄럽게 한 뒤 마디(최대 2코드)로 정리해요.
- **노래 파일 넣기**: 온셋 자기상관으로 템포와 박 위치를 추정하고, 마디 시작 위치는 마디 안 코드 바뀜이 가장 적은 쪽으로 골라요. 템포를 알면 직접 넣을 수 있어요. 분석은 모두 브라우저 안에서 해요.

**원곡 위에 얹기**: 파일을 분석하면 템포를 0.02 BPM 단위로 다듬고 첫 마디 시작 시각을 찾아요. 재생할 때 원곡을 같이 틀고 밴드를 그 박에 맞춰요(반복 없이 한 번). 템포가 절반/두 배로 잡히면 버튼으로 다시 분석하고, 남는 어긋남은 ±20ms 버튼으로 맞춰요. 믹서의 '이것만'으로 베이스만 남겨 들을 수 있어요.

인식 결과는 텍스트 칸에 적히니 틀린 마디는 고쳐 쓰면 바로 반영돼요. 코드 인식은 템플릿 매칭 추정이라 정답을 보장하지 않아요.

## 밴드
장르 7가지(팝, 록, 스피드 록, 발라드, 펑크, 셔플 블루스, 보사노바). 한 마디 16칸 패턴으로 정의돼 있어요(`STYLES`).
- 베이스: 루트·5도·옥타브·다음 코드로 반음 접근
- 키보드: 앞 코드와 가장 가까운 자리바꿈으로 이어 가는 보이싱 (일렉 피아노 FM / 오르간 / 아르페지오)
- 기타: 카플러스-스트롱 줄 합성, 다운·업 스트로크, 파워코드, 브리지 뮤트
- 드럼: 합성 킥·스네어·하이햇·림, 루프 마지막 마디 필인과 크래시

모든 소리는 Web Audio로 합성해요(샘플 파일 없음). 스페이스바로 재생/정지, 탭 템포, 반음 옮기기, 악기별 볼륨·끄기가 있어요.
