# PRD — 챙겨줘 트립 (가칭) v0.1

> 잘 까먹는 사람을 위한 여행 계획 앱.
> **"어디로, 누구랑"만 고르면 → 준비물·숙소·항공권·이동경로·맛집·D-day 할 일**을 한 번에 짜주고, 끝날 때까지 챙겨준다.

- 문서 상태: 초안 (기획)
- 작성일: 2026-11-07
- 관련 앱 참고: `miri/` (역산 스케줄러·선제 리마인더 패턴 재사용 후보)

---

## 1. 문제 정의 (Problem Statement)

여행 준비는 **항공권 → 숙소 → 일정 → 맛집 → 준비물 → 서류**까지 여러 앱(스카이스캐너, 아고다, 구글맵, 블로그, 메모장)을 오가야 하고, 각 일의 **마감 시점이 서로 다르다** (여권 갱신 D-60, ESTA D-14, 환전 D-3, 온라인 체크인 D-1 …).
특히 깜빡하는 사람·ADHD 성향·아이 동반 부모는 "계획은 세웠는데 **언제 무엇을 해야 하는지**"를 놓쳐 여권 만료, 비자 누락, 유모차·상비약 미지참 같은 **되돌릴 수 없는 실수**를 겪는다.
기존 여행 앱은 *예약*과 *정보*는 주지만, **구성원에 맞춘 할 일을 역산해 끝까지 챙겨주는 기능**은 없다.

## 2. 목표 (Goals)

| # | 목표 | 측정 |
|---|------|------|
| G1 | 여행 계획 생성 시간을 획기적으로 단축 | 코스+구성원 입력 → 전체 플랜 생성까지 **5분 이내** (중앙값) |
| G2 | "깜빡"으로 인한 여행 사고 감소 | 출발 후 설문 "빠뜨린 필수품/서류 있었다" 응답 **< 10%** |
| G3 | D-day 할 일을 실제로 완료하게 만들기 | 생성된 P0 할 일(서류·예약) 출발 전 완료율 **≥ 90%** |
| G4 | 구성원 맞춤의 체감 | "우리 가족에 맞춰졌다" 만족도 4.3/5 이상 |
| G5 (비즈) | 제휴 수익 기반 마련 | 숙소/항공 딥링크 클릭률 ≥ 30%, 예약 전환 ≥ 3% |

## 3. 비목표 (Non-Goals, v1)

1. **앱 내 직접 결제·예약** — 여행사 등록·환불 책임 등 규제 부담. v1은 제휴사 딥링크로 연결만.
2. **실시간 최저가 보장** — 가격은 "참고가 + 조회 시각" 표시. 가격 추적은 P1.
3. **비자·입국 요건의 법적 보증** — 정보 제공 + 공식 사이트 링크만, "최종 확인은 공식 출처" 고지.
4. **완전 자유 일정 AI 생성(전 세계 임의 도시)** — v1은 검증된 **큐레이션 코스** 중심. 자유 생성은 P2.
5. **여행 중 소셜/커뮤니티 피드** — 핵심 문제(까먹음)와 무관.

## 4. 핵심 개념

```
[국가] → [유명 코스 템플릿] + [여행 구성원] + [날짜·출발지·예산]
                         ↓  플랜 엔진
 ┌──────────┬──────────┬──────────┬──────────┬──────────┬────────────┐
 │ 준비물    │ 숙소      │ 항공권    │ 일자별    │ 인근 맛집 │ D-day      │
 │ (사람별)  │ 후보 3개  │ 후보·알림 │ 이동경로  │ (필터)   │ 역산 타임라인│
 └──────────┴──────────┴──────────┴──────────┴──────────┴────────────┘
                         ↓
              "챙김 엔진" — 완료할 때까지 반복 알림
```

### 4.1 입력 1 — 국가 & 유명 코스 (큐레이션 템플릿)

코스 = 일자별 스팟 목록 + 권장 숙박 거점 + 이동 수단 + 계절 메모.

| 국가 | 예시 코스 |
|------|-----------|
| 일본 | 오사카·교토·나라 4박5일 / 도쿄 근교(하코네) 3박4일 / 후쿠오카·유후인 2박3일 |
| 베트남 | 다낭·호이안 4박5일 / 하노이·하롱베이 3박5일 |
| 태국 | 방콕·파타야 4박6일 / 치앙마이 슬로우 5박 |
| 대만 | 타이베이·지우펀·스펀 3박4일 |
| 프랑스·스위스 | 파리 + 융프라우 7박9일 |

- 코스는 **기간 늘이기/줄이기**(하루 빼기 → 우선순위 낮은 스팟 자동 제거) 지원.
- 구성원에 따라 스팟 자동 치환 (예: 영유아 동반 → 장시간 하이킹을 키즈 친화 스팟으로).

### 4.2 입력 2 — 여행 구성원

| 필드 | 예시 | 플랜에 미치는 영향 |
|------|------|-------------------|
| 유형·나이 | 성인 2, 아이 5세, 영아 14개월, 부모님 72세 | 준비물(기저귀·유모차), 이동 강도, 숙소 침대 구성, 항공 좌석(배시넷) |
| 여권 만료일 | 2027-03-10 | "입국 시 6개월 이상" 규칙 → 갱신 알림 자동 생성 |
| 건강·제약 | 땅콩 알레르기, 무릎 불편, 복용약 | 맛집 필터, 계단 많은 스팟 경고, 상비약/영문 처방전 준비물 |
| 식성 | 매운 것 X, 채식 | 맛집 필터 |
| 담당자 | 엄마=예약, 아빠=짐 | 할 일·알림을 **담당자에게** 분배 |

입력 부담을 줄이기 위해 **"가족 프로필" 1회 저장 → 다음 여행 재사용**.

### 4.3 출력 모듈

1. **준비물** — 공통 + 사람별 + 국가별(전압·어댑터 타입, 우기 우산) + 코스별(사원 방문 → 긴 옷). 체크리스트, "캐리어 A/B" 배정, 출발 당일 **"문 앞 체크 5개"**(여권·지갑·폰·충전기·약).
2. **숙소** — 코스 거점 기준 반경 검색, 구성원 조건(패밀리룸, 엘리베이터, 아기침대) 필터, 후보 3개 비교 → 제휴 딥링크. (데이터 후보: Trivago/Agoda/Booking 제휴 API)
3. **항공권** — 출발 공항·날짜·인원(유아 포함) 기준 후보 + 가격 추이 + "지금 사도 될까" 힌트 → 딥링크. (후보: Skyscanner/Amadeus)
4. **상세 이동경로** — 일자별 타임라인: 스팟 → 스팟 이동 수단·소요시간·요금·교통패스 추천(예: 간사이 스루패스 vs 개별권 비교), 지도 앱 딥링크. 공항↔숙소 첫/마지막 이동 반드시 포함.
5. **인근 맛집** — 각 스팟 도보 10분 내, 구성원 필터(아이 의자, 알레르기, 채식) + 예약 필요 여부 → 예약 필요 시 **D-day 할 일로 자동 등록**.
6. **D-day 역산 타임라인** — 아래 5장.

## 5. D-day 역산 & 챙김 엔진 (핵심 차별점)

### 5.1 기본 템플릿 (국가·구성원 규칙으로 자동 가감)

| 시점 | 할 일 | 조건 |
|------|-------|------|
| D-90 | 여권 만료일 확인 → 6개월 미만이면 갱신 | 구성원 여권 만료일 기반 |
| D-60 | 항공권 예약 (가격 알림 시작) | |
| D-45 | 숙소 예약 / 인기 맛집·투어 예약 오픈일 체크 | 코스별 |
| D-30 | 비자·전자여행허가(ESTA, ETA 등) 신청 | 국가 규칙 |
| D-21 | 여행자 보험 가입, 국제운전면허(렌터카 시) | |
| D-14 | 교통패스·입장권 사전 구매, 유아 기내식·배시넷 요청 | |
| D-7 | eSIM/로밍, 환전·트래블카드, 상비약·처방전 영문 | |
| D-3 | 짐 싸기 1차 (체크리스트 70%), 날씨 확인 → 준비물 자동 보정 | |
| D-1 | 온라인 체크인, 짐 싸기 마감, 공항 이동 수단 확인 | |
| D-0 | 출발 3시간 전 "문 앞 체크", 공항 도착 목표 시각 알림 | |
| 여행 중 | 매일 아침 오늘 일정·예약 시각, 체크아웃 전 "두고 온 것" 알림 | |
| 귀국 | 면세 한도·세관 신고 알림 | |

### 5.2 까먹는 사람을 위한 알림 원칙

- **완료 전까지 끈질기게**: 미완료 시 리마인드 간격 단축 (3일 → 1일 → 반나절). "나중에"는 최대 N회.
- **한 번에 하나**: 오늘 해야 할 **딱 1~3개**만 홈에 노출. 전체 목록은 접어둔다.
- **바로 실행 버튼**: 알림에서 탭 1번으로 실행 화면(ESTA 공식 사이트, 체크인 페이지, 예약 딥링크)으로 이동.
- **담당자 분배 + 공유**: 동행자에게 할 일 넘기기, 완료 시 다른 구성원에게 알림.
- **마감 근접 에스컬레이션**: 비자처럼 *되돌릴 수 없는* 항목은 빨간 등급, 다른 구성원에게도 알림.
- **위치·상황 기반**(P1): 집을 나설 때 "여권 챙겼어요?", 숙소 체크아웃 시간 1시간 전 "충전기 확인".

## 6. 사용자 스토리

**깜빡하는 개인 여행자**
- 나는 국가와 코스만 고르고 싶다 — 일정 조사에 시간을 쓰지 않도록.
- 나는 오늘 할 여행 준비 1~2개만 알림으로 받고 싶다 — 압도되지 않도록.
- 나는 여권 만료가 걸리면 미리 경고받고 싶다 — 출국 불가 사태를 막도록.

**아이 동반 부모**
- 나는 아이 나이를 넣으면 기저귀·유모차·상비약이 준비물에 자동으로 들어가길 원한다.
- 나는 아이 의자 있는 맛집과 엘리베이터 있는 숙소만 보고 싶다.
- 나는 배우자에게 할 일을 넘기고 완료 여부를 보고 싶다.

**부모님 모시는 자녀**
- 나는 걷기 부담이 큰 스팟에 경고를 받고 대체 코스를 제안받고 싶다.
- 나는 부모님 복용약·영문 처방전 준비를 알림으로 받고 싶다.

**엣지 케이스**
- 날짜가 D-30 이내일 때 플랜을 만들면 → 이미 지난 할 일은 "긴급 지금 처리" 묶음으로 압축.
- 날짜·인원이 바뀌면 → 타임라인·준비물·숙소 조건을 재계산하고 바뀐 부분만 하이라이트.
- 오프라인(해외 데이터 없음) → 여행 중 일정·지도 링크·준비물은 로컬 캐시로 열람 가능.

## 7. 요구사항

### P0 — MVP (이게 없으면 출시 불가)

| ID | 요구사항 | 수용 기준 |
|----|----------|-----------|
| P0-1 | 국가 → 큐레이션 코스 선택 (5개국 × 2~3코스) | 코스 상세에 일자별 스팟·거점·이동수단이 보인다; 기간 ±1일 조정 시 스팟이 자동 가감된다 |
| P0-2 | 여행 구성원 입력 & 가족 프로필 저장 | 나이·여권 만료일·건강/식성 태그 입력; 다음 여행에서 불러오기 가능 |
| P0-3 | 구성원 맞춤 준비물 체크리스트 | 영유아 입력 시 유아용품 섹션 자동 생성; 사람별 탭; 체크 상태 저장 |
| P0-4 | D-day 역산 타임라인 생성 | 출발일 입력 시 5.1 템플릿이 날짜로 펼쳐짐; 여권 만료 < 출발일+6개월이면 갱신 할 일이 D-90에 생성 |
| P0-5 | 푸시 알림 + 미완료 반복 리마인드 | 미완료 할 일은 5.2 규칙대로 재알림; 알림 탭 시 해당 할 일 실행 화면으로 이동 |
| P0-6 | 일자별 이동경로 | 각 이동 구간에 수단·소요시간·대략 요금, 지도 앱 딥링크; 공항↔숙소 포함 |
| P0-7 | 스팟 인근 맛집 (필터) | 스팟별 3~5곳, 알레르기/아이동반 필터 동작 |
| P0-8 | 숙소·항공 후보 + 제휴 딥링크 | 거점 기준 숙소 3곳, 항공 후보 3개 + 조회 시각 표시; 예약 완료 체크 시 D-day 할 일 완료 처리 |
| P0-9 | 오프라인 열람 | 비행기 모드에서 일정·준비물·예약 정보 조회 가능 |

### P1 — 빠른 후속

- 동행자 초대·할 일 담당자 분배·완료 알림 공유
- 항공권 가격 추적 알림
- 출발 D-3 날씨 기반 준비물 자동 보정 (우산·패딩)
- 위치 기반 알림 (집 나설 때 여권, 체크아웃 전 두고 온 것)
- 예약 확인 메일 → 일정 자동 반영 (Gmail 연동)
- 캘린더(구글/애플) 동기화
- 여행 경비 정산(N빵)

### P2 — 향후 고려 (지금은 안 하지만 설계에 반영)

- 큐레이션 밖 임의 도시 AI 코스 생성 → 코스 데이터 스키마를 "스팟 그래프"로 일반화해 둘 것
- 앱 내 예약·결제
- 여행 후 회고/사진 자동 앨범, 다음 여행 준비물 학습("지난번 안 쓴 것 빼기")
- 다국어(외국인의 한국 여행)

## 8. 화면 구성 (IA 초안)

```
홈 ─ "오늘 할 일 1~3개" 카드 + D-day 카운터 + 다음 일정
 ├─ 새 여행 만들기: ① 국가 ② 코스 ③ 날짜·출발지 ④ 구성원 ⑤ 예산 → 플랜 생성
 ├─ 여행 상세 (탭)
 │    ├─ 타임라인(D-day 할 일)
 │    ├─ 일정(일자별 이동경로 + 맛집)
 │    ├─ 준비물(사람별/캐리어별)
 │    └─ 예약(항공·숙소·입장권 — 확정 정보 보관함)
 ├─ 가족 프로필
 └─ 설정(알림 강도: 순한 맛 / 보통 / 끈질긴 맛)
```

| 영역 | 후보 | 비고 |
|------|------|------|
| 코스·준비물·D-day 규칙 | 자체 JSON 큐레이션 | 규칙 엔진은 `조건 → 항목` 선언형으로 (예: `age < 3 → 기저귀`) |
| 숙소 | Trivago / Agoda / Booking 제휴 | 제휴 약관상 가격 캐시 허용 범위 확인 |
| 항공 | Skyscanner / Amadeus Self-Service | 유아 요금·배시넷 정보 가용성 확인 |
| 이동경로 | Google Directions / 현지 대중교통 API, 지도 딥링크 | v1은 소요시간 사전 계산 + 딥링크로 비용 절감 |
| 맛집 | Google Places / Tabelog(일본) | 리뷰 원문 저장 금지 약관 주의 |
| 입국 요건 | 외교부 해외안전여행, 각국 공식 사이트 | 수동 검수 주기 필요 |
| 앱 형태 | `miri/`처럼 Vite + React PWA → Capacitor로 iOS/Android | 반복 리마인드는 **네이티브 로컬 알림** 필요 (웹 푸시만으로는 iOS 신뢰도 낮음) |

## 10. 성공 지표

**선행 지표 (출시 후 1~4주)**
- 여행 플랜 생성 완료율 ≥ 70% (생성 시작 대비)
- 생성 후 7일 내 푸시 알림 허용률 ≥ 80%
- 알림 → 할 일 완료 전환율 ≥ 40%
- 주간 재방문(출발 전 기간) ≥ 3회

**후행 지표 (1~3개월)**
- 출발 전 P0 할 일 완료율 ≥ 90%
- 귀국 후 "빠뜨린 것 있었다" < 10%
- 두 번째 여행 생성률(재사용) ≥ 25%
- 제휴 예약 전환율 ≥ 3%
