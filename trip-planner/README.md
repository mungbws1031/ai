# 챙겨줘 트립 (MVP v0.1)

아이 동반 가족을 위한 여행 계획 PWA. **나라 → 코스 → 날짜 → 가족**만 고르면
일정·이동경로·맛집·준비물·D-day 할 일을 짜주고, 할 일을 끝낼 때까지 다시 알려준다.
기획: [`PRD.md`](PRD.md)

## 실행

빌드 없음. 정적 파일 서버로 열면 된다 (서비스워커는 `file://`에서 동작하지 않음).

```bash
cd trip-planner
python3 -m http.server 8000   # → http://localhost:8000
```

## 구성

| 파일 | 역할 |
|------|------|
| `data.js` | 큐레이션 데이터 — 9개 나라/지역, 16개 코스, 출발 공항, 월별 기후 |
| `engine.js` | 플랜 엔진 (순수 함수) — 일정 맞추기, D-day 역산 할 일, 사람별 준비물 |
| `app.js` | 화면·저장(localStorage)·알림·캘린더(.ics)·날씨 |
| `index.html` | 스타일 + 진입점 |
| `sw.js` | 오프라인 캐시, 알림 클릭 처리 |

## 코스 (16개)

- **일본**: 오사카·교토·나라+USJ / 도쿄+디즈니 / 후쿠오카·유후인 / 오키나와 렌터카 / 삿포로·오타루
- **중국·홍콩·대만**: 상하이+디즈니 / 베이징 만리장성·자금성 / 홍콩·마카오+디즈니 / 타이베이+예스진지
- **동남아**: 다낭·호이안 / 나트랑 / 방콕 / 푸껫 / 세부 / 코타키나발루 / 싱가포르

## 어떻게 맞춰주나

- **일정**: 박 수를 줄이면 우선순위 낮은 날부터 빠지고, 늘리면 '자유 일정' 날이 들어간다. 어르신·걷기 힘든 가족이 있으면 계단 많은 곳에 쉬운 길을 붙인다.
- **할 일**: 출발일에서 거꾸로 날짜를 잡는다. 여권(귀국일+6개월 규칙), 나라별 입국 서류(VJW·TDAC·eTravel·MDAC·SG Arrival Card 등), 코스 속 예약(USJ·디즈니·유후인노모리…), 아기 배시넷, 복용약, 알레르기 카드 등. 빨간 줄 = 놓치면 되돌릴 수 없는 일.
- **준비물**: 공통 + 출발 월의 현지 기후 + 사람별(아기 기저귀 수량, 아이 놀잇감, 약, 알레르기) + 복장 규정.
- **맛집**: 날마다 근처 추천 + 아이 동반/채식/안 매운 것 필터 + 지도 검색 링크.

## 알림 — 끝낼 때까지

- 브라우저 알림: 기한이 된 할 일을 강도별(하루/반나절/3시간) 간격으로, 출발 7일 전부터는 두 배로 자주. 앱이 열려 있거나 다시 열 때 확인한다.
- **캘린더 내보내기(.ics)**: 앱을 닫아도 휴대폰 기본 캘린더가 날짜마다 알려준다 (빨간 항목은 하루 전 알림 추가). 서버 푸시가 없는 지금 버전에서 가장 확실한 방법.
- 아이폰은 Safari "홈 화면에 추가" 후에 알림을 켤 수 있다.

## 범위 밖 (이번 버전)

- 항공·숙소 **예약 연동 없음** — 할 일에 검색 링크만 걸고, 예약 내용은 '메모' 탭에 적어 오프라인으로 본다.
- 서버·계정 없음 — 모든 데이터는 기기 안(localStorage)에만 저장.
- 입국 규정은 자주 바뀐다. 앱은 정보 제공이며 화면마다 외교부 해외안전여행 확인을 안내한다.
- 날씨는 출발 14일 이내일 때 Open-Meteo 무료 예보를 불러온다 (오프라인이면 생략).
