# 품목별 체크 노트 — 가전 / 유아용품

## 가전

**가격에 크게 영향 주는 것**
- 모델명과 제조 연월: 본체 뒷면·바닥 명판 사진을 요청한다. 연식이 시세의 핵심이다.
- 정상 작동 여부, 소음·냄새, 리모컨·어댑터 유무
- 소모품 상태: 청소기 배터리·필터, 공기청정기 필터, 밥솥 패킹, 정수기 필터
- 박스·설명서 유무 (있으면 +5~10% 정도 기대)
- 무상 A/S 기간 남았는지 (남았으면 판매글에 꼭 쓰기)

**감가 감각 (대략, 브랜드·인기 모델에 따라 크게 다름)**
- 1년 이내 깨끗: 새 제품 최저가의 60~75%
- 2~3년: 40~55%
- 4~5년 이상: 20~35%, 대형가전은 운반 문제로 더 낮음
- 다이슨·발뮤다·LG 오브제·삼성 비스포크 등 인기 브랜드는 감가가 느리다.
위 숫자는 시세 데이터가 부족할 때의 보조 근거로만 쓰고, 실제 비교 매물이 있으면 그걸 우선한다.

**판매글 팁**
- "직접 작동 확인 가능" 문구가 거래 성사율을 높인다.
- 대형가전(세탁기·냉장고)은 운반 조건(엘리베이터, 층수, 직접 가져가셔야 함)을 꼭 쓴다.

## 유아용품

**안전 먼저 — 팔면 안 되거나 조심할 것**
- **카시트**: 사고 이력이 있으면 팔지 않도록 권한다. 사고 없음, 제조일(시트 라벨)을 명시한다. 제조 후 오래된 제품은 사용 권장기한을 확인하라고 안내한다.
- **리콜 대상 제품**: 모델명이 나오면 리콜 여부를 검색해 본다(소비자24, 제품안전정보센터 등). 해당되면 판매를 말린다.
- 젖병 꼭지, 쪽쪽이, 개봉한 분유·기저귀처럼 위생·소모성인 것은 거래가 어렵거나 무료나눔이 낫다고 알려준다.
- 유통기한 있는 것(분유·이유식)은 기한을 명시한다.

**가격에 크게 영향 주는 것**
- 브랜드(스토케, 부가부, 싸이벡스, 에르고베이비 등은 감가가 느림)
- 구성품(카시트 이너시트, 유모차 레인커버·컵홀더, 아기띠 신생아 패드)
- 세탁·소독 여부, 흡연·반려동물 여부 → 판매글에 꼭 쓰기
- 사용 기간이 짧은 경우가 많아 "N개월 사용"을 강조하면 좋다.

**판매글 팁**
- 구매자 대부분이 부모라 **위생·안전 정보**가 가장 중요하다. 상태 설명을 다른 품목보다 조금 더 꼼꼼히.
- 계절템(아기띠 여름 메쉬, 겨울 방한커버)은 시즌 직전에 올리면 잘 나간다고 조언한다.
- 묶음 판매(작아진 옷, 장난감 여러 개)는 개별보다 묶음 한 번에가 빠르다.
