# AI 오피스 (office/)

도트 이미지 사무실에서 총괄(GM)에게 업무를 지시하면, GM이 키워드로 필요한 팀을 고르고
직원을 투입해 진행하는 모습을 보여주는 단일 파일 웹앱입니다.

- 실행: `office/index.html`을 브라우저로 열기 (빌드/서버 불필요)
- 팀 7개 기본 제공(기획·디자인·기구·전자·인허가QA·리서치·문서), 최대 8팀까지 추가 가능
- 직원 수는 키워드 적중 수에 따라 1~3명
- "Claude용 브리핑 복사"로 투입 팀/역할이 담긴 요청문을 만들어 실제 검토에 사용

주의: 화면의 진행/완료는 업무 배분 시뮬레이션이며 실제 AI 검토 결과가 아닙니다.
