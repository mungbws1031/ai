# 근육 자극 플래너 (muscle-planner)

운동을 하면 **어느 근육에 얼마나 자극이 가고, 몇 주 뒤 얼마나 자랄지**를 연구 결과를 바탕으로 추정하고, 원하는 체형에 맞는 주간 운동 계획을 세우는 단일 파일 PWA입니다.

## 실행
```bash
cd muscle-planner
python3 -m http.server 8000   # http://localhost:8000
```
`index.html`을 그냥 열어도 동작합니다(이 경우 오프라인 캐시/설치 비활성).

## 탭
- **내 루틴 시뮬레이터**: 운동 × 주간 세트 × 강도(실패까지 남은 횟수) → 근육 22곳별 유효 세트, 실사형 해부도 위 앞/뒤 근육 히트맵, 근두께 변화 추정 범위, 제지방 증가 추정, 불균형 경고
- **목표 체형 플랜**: 해부도 이미지 카드(`goals/*.webp`, 집중 근육이 붉게 표시)로 넓은 어깨·힙업·거북목 교정 등 목표를 선택 + 운동일/시간/도구 → 목표 근육 주 10–16세트, 나머지 유지 볼륨이 되도록 자동 배분하고 요일별로 나눔
- **거북목·자세 교정**: 고개 각도별 목 하중(Hansraj 2014, 각도별 해부도 키프레임), 옆모습 사진으로 CVA(두개척추각) 측정, 거북목·라운드숄더·골반 전방경사 프로그램(루틴에 바로 추가)
- **팔 올리는 각도 (국민체조)**: 외전 각도 슬라이더(0/90/150/180° 뒷모습 해부도 키프레임) → 견갑골/상완골 각도(2:1 리듬), 각도별 삼각근·승모근·전거근 활성 모식도, 체조 시 팔 높이 가이드
- **운동 원리**: 근비대 과정(자극→신호→합성→적응)과 장력·볼륨·과부하·빈도·영양·유산소·간섭효과·자세·국소감량·개인차 원리, 각 원리가 계산에 반영되는 방식
- **근거 논문**: 계산 규칙마다 기대는 논문 목록

## 계산 방식 (휴리스틱)
- 유효 세트 = 세트 × 기여도(주동근 1 / 협응근 0.5 / 보조 0.25) × 근접 실패 계수(1.0/0.9/0.6/0.3) × 운동 부하 계수
- 근두께 변화(%) ≈ 12 × 경력계수 × 나이·식사·단백질 보정 × (1 − e^(−세트/9)) × (주/12)^0.85, 개인차를 반영해 ×0.5–1.5 범위로 표시
- 유산소(걷기·조깅·인터벌·줌바)는 주 N회 × M분으로 입력 → MET 기반 순 소모 칼로리((MET−1)×체중×시간), 체지방 감소(계산값의 30–60%, 보상작용 반영), 최대산소섭취량 향상, WHO 중강도 환산(고강도 ×2)
- 국민체조 등 가동성 운동은 근비대 기여 ×0.1, 스트레칭은 0

모든 수치는 연구 평균 경향을 단순화한 **추정치**이며 물리적 측정이나 의학적 처방이 아닙니다.

## 구성
