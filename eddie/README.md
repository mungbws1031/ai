# 에디의 하루 (Eddie's Day) — MVP Alpha

ADHD 사용자의 하루 루틴 동행 앱. 시간 블라인드·복약 누락·루틴 이탈을 캐릭터 **에디**와 함께 완화한다.

> 본 구현은 `PRD-EDDIE-0.1`의 **MVP Alpha 범위(§10)** 를 **Next.js 14 + TypeScript + Tailwind** 웹앱으로 구현한 것이다.
> 데이터는 기기 로컬(localStorage)에 저장되며, 알림은 브라우저 Notification API + 인앱 스케줄링으로 동작한다.

## 실행

```bash
npm install
npm run dev      # http://localhost:3100
npm run build    # 프로덕션 빌드
npm test         # 핵심 로직 유닛 테스트 (vitest)
```

## 화면 구성

하단 탭 6개로 구성된다.

- **오늘** (`/`) — 에디 시계, 출발 카운트다운, 오늘 약, 오늘 일정, 아침 루틴
- **루틴** (`/routines`) — 아침/저녁 루틴 빌더 + 원탭 체크인
- **달력** (`/calendar`) — 월 뷰 + 일자별 마커 + 일정 추가/완료
- **정리** (`/clean`) — 방 사진 AI 분석(BYOK)으로 시간별 청소 우선순위 제안
- **에디** (`/eddie`) — 캐릭터 반응, 너그러운 스트릭
- **더보기** (`/more`) — 복약·출발·제자리·취침·5분 정리·알림 설정·면책/개인정보
- **온보딩** (`/onboarding`) — 어려움 선택 기반 첫 설정

## 설치형 PWA (오프라인 + 홈 화면)

ADHD 사용자가 앱을 자주 열고 할 일을 잊지 않게 하려면 "손에 닿는 곳"에 있어야 한다.
그래서 **홈 화면에 추가 가능한 PWA**로 만들었다.

- `public/manifest.webmanifest` + `public/icon-*.png`(에디 아이콘, `gen_icons.py`로 생성) + `public/sw.js`
- 서비스 워커 전략: 내비게이션(HTML)은 **network-first**(최신 화면 우선, 스테일 HTML 방지), 정적 해시 자산은 **cache-first**. → 오프라인에서도 앱이 열린다.
- 알림은 서비스 워커가 있으면 `registration.showNotification`으로 띄워 **트레이에 남고, 클릭하면 앱으로 돌아온다**(없으면 `new Notification` 폴백).
- 더보기 화면의 **"홈 화면에 추가"** 카드로 설치 유도(`beforeinstallprompt`; iOS는 공유→홈 화면에 추가 안내).
- 베이스 경로는 `NEXT_PUBLIC_BASE_PATH`로 주입해 로컬(`/`)·Pages(`/ai/eddie`) 양쪽에서 동작.

> 웹 한계: 앱이 완전히 닫힌 상태의 예약 백그라운드 알림은 푸시 서버가 필요해 아직 불가하다.
> 설치형 PWA + 트레이 알림으로 신뢰성을 최대한 끌어올린 단계다.

## 비행 워크플로우 (출발 시각 기준 타임라인)

비행기 일정(제목에 비행기/항공/공항 등)이면 출발 시각 기준으로 당일 동선을 자동 편성한다.

- `lib/flight-plan.ts` — 국내/국제 + 집→공항 이동시간으로 단계별 '출발 N분 전' 계산
  (집에서 출발 → 공항 도착·체크인 → 보안검색 → (출국심사) → 탑승구 대기 → 탑승)
- `components/EventRow.tsx`(FlightPanel) — 시각 미리보기 → 담기: 전날 준비물은 **할 일**(전날 20시), 당일 동선은 **마감 알림**(각 시각 10·5분 전·정시). 자정 넘기는 단계는 전날로 자동 배치.

## 음성으로 빨리 담기 🎙️

적는 마찰이 곧 망각인 ADHD를 위해, 말로 담을 수 있다(브라우저 내장 음성인식, 키·서버 불필요).

- `components/QuickTodos.tsx` — 🎙️ 버튼 → `SpeechRecognition`(ko-KR)로 받아쓰기. "**에디~ 메모해줘** …" 같은 호출/명령어는 `stripWakeWords`로 제거하고 내용만 캡처.
- 인식 결과는 기존 파이프라인으로 → 날짜 표현 있으면 캘린더, 없으면 할 일.
- 미지원 브라우저(iOS Safari 등)는 안내 토스트로 폴백.
- **핸즈프리("에디야" 호출)**: 🎧 토글을 켜면 연속 인식 + 자동 재시작으로, 마이크를 누르지 않고 "에디야~" 하고 부르면 다음 말을 메모로 캡처(한 문장에 "에디야 내일 치과"도 가능). 앱이 열려 있는 동안만 동작(웹 한계상 앱 종료 상태의 상시 대기는 불가).

## 집중 모드 (지금 한 가지 + 타이머)

ADHD의 시작 장벽·시간 감각·멀티태스킹을 돕는 실행 도구. 키·서버 불필요, 모든 기기 동작.

- `components/FocusMode.tsx` — 할 일 하나를 전체화면으로 크게 띄우고 뽀모도로식 타이머(5/15/25분, +5분, 리셋). 끝나면 진동 + 부드러운 응원, '완료로 표시'로 할 일 체크.
- `components/QuickTodos.tsx` — 미완료 할 일마다 🎯 버튼으로 집중 모드 시작.

## 할 일 → 날짜 자동 인식 (캘린더로)

'할 일 빨리 담기'에 **'내일', '다음주 화요일', '6/27 3시'** 같은 표현이 있으면 캘린더 일정으로 넣는다.

- `lib/parse-when.ts` — 규칙 기반 한국어 날짜/시각 파서(오늘/내일/모레, 이번주·다음주·다다음주 요일, M월D일, 다음달 D일, M/D, HH:mm, 오전·오후 N시반). 표현은 제목에서 제거.
- `components/QuickTodos.tsx` — 날짜 인식 시 `addEvent`(시각 포함)로 달력에, 아니면 일반 할 일. (테스트 10건 추가)

## 마감 알림 (카운트다운)

공항·놀이동산처럼 복잡한 곳에서 "몇 시까지" 할 일을 넣어두면, **N분 전·정시**에 알리고 남은 시간을 보여준다.

- `Deadline { time, leadMins[], date }` + `AppState.deadlines`, 오늘 화면의 `components/DeadlineList.tsx`(라이브 카운트다운)
- 미리 알림 칩(30·10·5분 전, **정시 0은 항상 포함**) → 스케줄러가 (마감 − lead)분에 `deadline:<id>:<lead>` 알림(20초 틱)
- 임박(≤10분)하면 카드 강조. .ics로 캘린더에 넘기면 앱이 꺼져도 알림(위 캘린더 연동과 조합).

## 유형별 준비 체크리스트 (출장·여행·면접 등)

일정 제목에 키워드가 있으면 단계별 준비 할 일을 'D-며칠' 단위로 한 번에 담아준다(AI 키 불필요).

- `lib/prep-templates.ts` — 출장/여행/면접/병원/결혼식/시험 템플릿. 예: **출장 → 출장 신청서 작성(D-3)**·교통/숙소 예약(D-3)·짐 싸기(D-1)·당일 챙기기.
- `components/EventRow.tsx` — 제목 매칭 시 "📋 {유형} 준비 체크리스트" → 펼쳐보기 → 담기 → 각 항목이 `remindDate=일정일−daysBefore`, 09:00 알림.

## 일정 미리 알림 + AI 준비 계획

일정 하나를 잘 치르도록, 며칠 전부터 여러 번 알리고 준비 할 일을 짜준다.

- **미리 알림(D-7/D-2/D-1)**: 일정에 `leadDays` 설정 → 스케줄러가 각 날(일정 시각, 없으면 09:00)에 `event:<id>:lead:<n>` 알림. 추가 폼·각 일정의 `⋯` 패널에서 칩으로 선택.
- **AI 준비 계획(BYOK)**: `lib/plan-ai.ts`가 일정(제목·날짜·선택 장소)에 맞는 준비 할 일을 'D-며칠' 단위로 제안 → 선택 시 할 일로 등록(remindDate = 일정일 − daysBefore). 약속이면 장소·시간 확인, 교통, 가져갈 것 등 포함.
  - **장소 맞춤 스타일 추천**: 가는 곳·계절에 맞춰 💄화장·👕옷·👟신발을 추천(면접→단정, 등산→기능성+등산화, 결혼식→하객룩 등). 일정 패널의 장소 입력(선택)으로 정확도 향상.
- `components/EventRow.tsx` — 일정별 완료/삭제 + 미리 알림 + 준비 계획 + 보내기 패널.

## OS 캘린더 연동 (.ics / 구글 캘린더)

PWA는 닫히면 알림을 못 주므로, 일정을 **OS 캘린더에 위임**해 백그라운드 알림을 확보한다.

- `lib/ics.ts` — 일정을 iCalendar(.ics)로 생성. `leadDays`(7·2·1일 전)를 **VALARM**으로, 시각 있으면 시작 시각 알람(`-PT0M`)도 포함 → OS 캘린더가 앱과 무관하게 여러 번 알림.
- `components/EventRow.tsx` — 일정별 **📅 캘린더에 추가(.ics 다운로드)** + **구글 캘린더** 링크
- `components/CalendarExport.tsx` — 다가오는 일정 전체를 한 파일로 내보내기
- 종일/시각 일정 모두 지원(종일=VALUE=DATE). 한글 제목 escape 처리.

## 친구와 일정 공유 (서버 없이 링크 교환)

서버가 없는 정적 PWA라 실시간 동기화는 불가하므로, **링크에 일정을 실어** 주고받는다.

- `lib/share.ts` — 일정(date/time/title)을 base64url로 인코딩해 `#sched=` 해시 링크 생성/복호화
- `components/ScheduleShare.tsx` — 다가오는 내 일정을 링크로 묶어 카톡/문자/복사로 전송
- `components/ScheduleImport.tsx` — `#sched=` 링크로 들어오면 미리보기 → 중복 제외 후 선택 가져오기
- 둘 다 설치해 **서로** 주고받을 수 있음(보낸 시점 스냅샷, 자동 동기화 아님)

## 공지·노션에서 일정 가져오기 (BYOK)

하이클래스 등 학교 알림장이나 **노션 페이지·데이터베이스 내용**을 달력 화면에 붙여넣으면, 본인 Anthropic 키로
**날짜 있는 일정**과 **준비물·제출 같은 할 일**을 뽑아 **확인 후 선택 등록**한다(자동으로 무단 추가하지 않음).

- `lib/notice-ai.ts` — 구조화 출력으로 `{events, todos}` 추출. 표/CSV/마크다운(노션 DB 내보내기)도 각 행을 항목으로 매핑, 완료 표시 행은 제외. 상대 날짜는 오늘 기준 환산
- `components/NoticeImport.tsx` — 붙여넣기 → 뽑기 → 체크박스 선택 → `addEvent`/`addTodo` 등록
- 노션 자동 연동(API 직접 호출)은 CORS·토큰·서버 필요로 불가 → 복사·붙여넣기 방식으로 대체

## 정리 도우미 — 방 사진 AI 분석 (BYOK)

`/clean` 탭은 방 사진을 올리면 **10/30/60분** 시간 예산에 맞춰 "어디부터 치우면 가장 깨끗해 보일지"
순서·소요시간·기여도(효과 큼/보통/마무리)를 제안한다.

- **모델**: `claude-opus-4-8` (vision), 구조화 출력(`output_config.format`)으로 계획을 받는다 (`lib/clean-ai.ts`).
- **BYOK**: 정적 사이트라 서버가 없어, 사용자 본인 Anthropic API 키로 브라우저에서 직접 호출한다
  (`anthropic-dangerous-direct-browser-access`). 키는 기기 localStorage에만 저장된다.
- **프라이버시**: 사진 전송 전 명시 동의를 받으며(NFR-PR-001), 사진은 분석 목적으로 Anthropic API에만
  전송되고 앱에 저장하지 않는다. 업로드 이미지는 전송 전 긴 변 1568px로 축소한다. 데이터 내보내기에서 API 키는 제외된다.
- 향후 백엔드/프록시를 두면 키 노출 없이 공용 서비스로 전환할 수 있다.

## 핵심 설계 노트

### 빠른 시계 (FR-101 / UO-3)
- 오프셋은 **날짜를 시드로 한 결정적 난수**로 5~10 정수 분에 매핑한다(`lib/clock.ts`). 서버 의존이 없다.
- 모듈은 **raw 오프셋을 반환하는 export를 제공하지 않는다.** 외부에는 "오프셋이 적용된 시각"만 노출되어 어떤 화면·로그에서도 정확한 분을 알 수 없다. (테스트로 검증 — `clock.test.ts`)
- 출발 카운트다운도 에디 시계 기준으로 계산해 앱 전체가 일관되게 "조금 빠르게" 느껴진다.

### 너그러운 스트릭 (FR-504)
- `total`(누적 잘 보낸 하루)은 **절대 0으로 리셋되지 않는다.**
- `momentum`(요즘 흐름)은 하루 빈칸을 **다리 놓아 이어주고**, 연속 2일 비활동에서만 쉬어가며 음수가 되지 않는다.
- 압박형 연속일수를 강조하지 않는다.

### 알림 (FR-102/201/203)
- 총량 상한·중복 방지·톤(부드럽게/단호하게)을 지킨다(`lib/notifications.ts`).
- 놓친 복약을 늦게 기록하면 `recovered` 상태로 보존한다(삭제 아님, PRD §8).
