업체 이메일 상세 해석

메일의 문장을 실제 설계 판단 관점에서 하나씩 풀어서 정리했습니다.

리더 출력·리더 안테나
＋
태그 안테나 크기·구조
＋
배치·금속·공진 상태
1

“인식거리는 리더 출력과 안테나 크기에 영향을 받는다”

맞는 설명입니다. NFC/RFID의 인식거리는 태그 칩 하나만으로 정해지지 않고 리더와 태그의 안테나 시스템 전체 조합으로 결정됩니다.

  • 리더기 RF 출력
  • 리더 안테나 크기와 매칭
  • 태그 안테나 면적
  • 두 안테나 사이 거리와 정렬
2

“초소형 태그는 약 5–10 mm”의 의미

5–10 mm는 NTAG213 자체의 고정 사양이라기보다, 안테나를 극도로 작게 만든 조건에서 현실적으로 검토하는 거리로 이해하는 것이 적절합니다.

주의: 이 숫자가 ‘예상치’인지 ‘보장치’인지 업체에 구분해서 확인하세요.
3

“NTAG213은 10×20 mm 정도”의 의미

칩 자체가 10×20 mm라는 뜻이 아닙니다. 보통은 칩 + 안테나 전체 태그/Inlay 크기를 말합니다. 칩 자체는 훨씬 작고, 실제 면적 대부분은 안테나가 차지합니다.

4

“PCB 타입은 Ø6.75 mm까지”의 의미

필름형 Inlay 대신 PCB 동박 패턴으로 안테나를 설계하면 구조를 더 정밀하고 작게 만들 수 있다는 뜻입니다. 다만 작아진 만큼 안테나 면적도 줄어 인식거리에는 불리할 수 있습니다.

5

NTAG213과 ICODE는 같은 계열이 아닙니다

NTAG213은 NFC Type 2 / ISO 14443A 계열이고, ICODE SLIX 계열은 NFC Type 5 / ISO 15693 계열입니다. 따라서 “NTAG213”과 “ICODE라서 리더 변경”이 한 메일에 함께 나오면 최종 칩을 다시 확인해야 합니다.

6

리더기 변경 이야기가 나온 이유

ICODE를 사용할 경우 리더가 ISO 15693을 지원해야 합니다. 따라서 업체가 ICODE 계열 태그를 제안하면서 ISO 15693 대응 리더로 변경하자는 취지로 이해할 수 있습니다.

Q&A

지금까지 질문한 내용 — 상세 답변

검색창에 PCB, FCC, 메모리, 장비, ICODE 같은 키워드를 입력하면 관련 질문만 볼 수 있습니다.

1. 업체 이메일은 무슨 뜻인가?

인식거리는 리더 출력, 리더 안테나 크기, 태그 안테나 크기의 영향을 받습니다. 초소형 태그는 약 5–10 mm 수준을 검토하고 있으며, 일반적인 필름형 태그보다 PCB 방식으로 더 작게 만들 수 있다는 설명입니다.

메일에서 확인해야 할 포인트

  • “5–10 mm”가 예상치인지 보장치인지
  • “NTAG213 최소 10×20 mm”가 칩 크기가 아니라 일반적인 태그/Inlay 크기라는 점
  • Ø6.75 mm PCB 태그를 실제 제품 안에 넣었을 때도 같은 거리가 나오는지
  • 최종 칩이 NTAG213인지 ICODE인지

ICODE를 사용한다면 ISO 15693 지원 리더가 필요합니다.

2. NFC 태그에는 PCB 타입과 다른 타입도 있나?

네. 대표적으로 Inlay, 라벨/스티커, PCB, FPCB, 코일, 금속 대응형이 있습니다. 차이는 주로 안테나를 어떤 재료와 구조로 만드는지입니다.

쉽게 구분하면: 일반 스티커 태그는 Inlay/Label, 아주 작고 구조적으로 정밀해야 하면 PCB·FPCB를 검토합니다. 금속 가까이에 붙여야 하면 Ferrite/차폐 구조를 포함한 Metal-mount 타입을 검토합니다.

3. Ø6.75 mm PCB 태그 같은 실제 제품이 있나?

네. 시장에는 직경 약 6–7 mm급의 초소형 PCB RFID/NFC 태그 제품 사례가 있습니다. 이전 검토에서 Ø6.75 mm + ICODE SLIX 계열 사례가 확인되었습니다.

SAG RFID PCB Tag 제품 페이지 ↗

중요한 것은 “제작 가능한 크기”와 “필요한 인식거리”를 동시에 만족하는지 실제 조합으로 확인하는 것입니다.

4. FCC 인증과 PCB 태그도 관련이 있나?

관련은 있지만 FCC에서 핵심은 능동적으로 13.56 MHz RF를 발생시키는 리더기와 리더 안테나입니다. 태그 종류는 리더와의 결합 상태나 공진에 일부 영향을 줄 수 있지만, 일반적으로 리더 쪽이 더 중요합니다.

완제품 내부에 리더를 넣거나 안테나 구조를 바꾸면, 기존 인증만으로 충분한지 공인 시험소에 확인하는 것이 안전합니다.

5. 태그에는 정보를 어떻게 넣고, 얼마나 저장할 수 있나?

Reader/Writer 또는 NFC 지원 스마트폰을 이용해 태그에 데이터를 기록합니다. NFC에서는 URL, 텍스트, ID 등을 NDEF 형식으로 저장하는 경우가 많습니다.

칩방식사용자 메모리용도 예
NTAG213NFC Type 2 / ISO 14443A144 bytesURL, 제품 ID, 짧은 텍스트
ICODE SLIX2NFC Type 5 / ISO 15693316 bytes제품 ID, URL, 간단한 데이터

실무에서는 큰 데이터를 태그에 직접 넣기보다 UID 또는 짧은 제품 ID/URL만 저장하고 실제 정보는 서버에 저장하는 방식이 관리하기 좋습니다.

6. 회사에서 태그에 정보를 넣으려면 특별한 장비가 필요한가?

태그 자체를 제조하는 것이 아니라 완성된 Blank 태그에 정보를 기록하는 것이라면 특별한 대형 설비는 필요하지 않습니다.

PC + Reader/Writer + 생산 프로그램 + 위치 고정 지그 정도면 생산라인을 구성할 수 있습니다.

생산 프로그램은 제품 SN/URL 생성 → Write → 즉시 Read-back → PASS/FAIL → DB 저장까지 자동화할 수 있습니다.

7. 태그 자체를 회사에서 직접 제조하려면?

이 경우에는 PCB/FPCB 안테나 제작, 칩 실장 또는 본딩, 공진 튜닝, 검사 공정이 필요합니다. 개발 단계에서는 VNA(네트워크 분석기)나 임피던스 측정 장비도 유용합니다.

일반적으로는 태그 자체는 전문 업체에서 제작받고, 자사에서는 데이터 기록·검증만 수행하는 방식이 현실적입니다.
