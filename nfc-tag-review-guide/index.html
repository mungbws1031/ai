1. 이메일 상세 해석

업체가 전달한 내용의 정확한 의미

메일의 각 문장을 서로 겹치지 않게 원인, 크기, 칩과 리더 문제로 나누었습니다.

1

인식거리는 리더와 태그 양쪽의 영향을 받습니다

리더 출력과 리더 안테나 크기, 태그 안테나 크기가 함께 인식거리에 영향을 줍니다. 따라서 태그 칩 모델만으로 거리를 확정할 수 없습니다.

2

5–10 mm는 초소형 조건의 검토 거리입니다

이 수치는 NTAG213의 고정된 공식 거리라기보다 안테나를 매우 작게 만든 조건에서 검토하는 거리로 이해해야 합니다.

  • 예상치인지 보장치인지 확인
  • 제품 내부 장착 상태의 수치인지 확인
3

10×20 mm는 칩 크기가 아니라 태그 전체 크기입니다

칩 자체는 매우 작고, 태그 면적 대부분은 전력을 받고 통신하는 안테나가 차지합니다. 메일의 10×20 mm는 일반적인 NTAG213 태그/Inlay 제작 크기를 뜻하는 것으로 보는 것이 적절합니다.

4

PCB 타입 Ø6.75 mm는 제작 가능성에 대한 설명입니다

필름형 Inlay 대신 PCB 동박 패턴을 사용하면 더 정밀하고 작은 구조를 만들 수 있다는 의미입니다. 다만 작아진 안테나가 필요한 인식거리까지 보장하는지는 별도 검증입니다.

메일에서 혼재된 부분

NTAG213과 ICODE는 서로 다른 계열입니다. “NTAG213 최소 크기”와 “ICODE이므로 리더 변경”이 함께 적혀 있으므로, 최종 제안 태그가 무엇인지 다시 확인해야 합니다.

최우선 질문: 최종 적용 칩은 NTAG213입니까, ICODE 계열입니까?

메일을 한 문장으로 정리하면

태그를 작게 만들수록 인식거리는 짧아질 수 있고, PCB 방식으로 Ø6.75 mm 수준을 검토할 수 있으나, ICODE를 선택한다면 ISO 15693 지원 리더가 필요하므로 실제 제작 크기와 거리를 다시 확인하겠다는 뜻입니다.

4. 칩과 리더 선택

NTAG213과 ICODE는 같은 것이 아닙니다

이 섹션에서는 통신 규격과 리더 호환성만 다루고, 저장용량은 다음 섹션에서 한 번만 설명합니다.

NFC TYPE 2

NTAG213

ISO 14443A
  • 계열: NFC Forum Type 2
  • 리더 조건: ISO 14443A 지원
  • 일반적인 활용: URL, 제품 ID, 짧은 NFC 데이터
  • 주의: “NTAG213”이라는 칩명과 실제 태그 크기는 같은 개념이 아닙니다.
NFC TYPE 5

ICODE SLIX2

ISO 15693
  • 계열: NFC Forum Type 5
  • 리더 조건: ISO 15693 지원
  • 일반적인 활용: 제품 식별과 간단한 데이터 저장
  • 주의: NTAG213과 리더 지원 규격이 다를 수 있습니다.
NTAG213을 최종 선택했다면태그 크기와 인식거리 샘플을 확인하고 현재 리더의 ISO 14443A 지원 여부를 확인합니다.
ICODE를 최종 선택했다면정확한 ICODE 모델과 ISO 15693 지원 리더 사용 여부를 확인합니다. 업체가 ACM1552U-Z2 계열을 언급한 이유도 이 부분으로 볼 수 있습니다.

6. 생산 적용

회사에서 필요한 장비와 생산 절차

정보 기록 공정과 태그 자체 제조 공정을 분리해 설명합니다.

A. Blank 태그에 정보 기록

대형 제조 설비는 필요하지 않습니다

완성된 태그를 구매해 제품별 정보를 쓰는 경우입니다.

  • 1PC — 생산 프로그램 실행
  • 2Reader/Writer — 최종 태그 규격 지원
  • 3생산 프로그램 — SN/URL 생성, Write, Read-back
  • 4위치 고정 지그 — 태그와 리더 위치 반복성 확보
  • 5DB — 제품번호·UID·기록일시·결과 저장
B. 태그 자체 직접 제조

제조와 RF 측정 설비가 필요합니다

PCB/FPCB 안테나와 칩 조립부터 직접 수행하는 경우입니다.

  • 1PCB/FPCB 안테나 제작
  • 2칩 실장 또는 본딩
  • 313.56 MHz 공진·매칭 튜닝
  • 4VNA 또는 임피던스 측정 장비
  • 5기능·인식거리 검사 공정
현실적인 구조: 전문 업체에서 Blank 태그를 제작받고 자사에서는 기록·검증만 수행하는 방식이 단순합니다.
