# 손글씨 폰트 공방 (handfont)

글자를 한 자씩 손으로 쓰면 **내 글씨체로 된 TrueType 폰트(.ttf)** 를 브라우저에서 바로 만들어 주는 단일 파일 웹앱입니다. 서버·외부 라이브러리 없이 동작합니다(웹폰트 UI 글꼴만 Google Fonts 사용, 오프라인이면 시스템 글꼴로 대체).

## 실행
```bash
cd handfont
python3 -m http.server 8000   # http://localhost:8000
```
`index.html`을 더블클릭해서 열어도 됩니다.

## 사용 순서
1. **글자 목록**에 쓸 글자를 넣습니다. 프리셋(대문자/소문자/숫자/문장부호/한글) 또는 문장을 붙여 넣으면 중복 없이 추가됩니다.
2. **필기 칸**에 마우스·손가락·펜으로 씁니다. 빨간 기준선(0)에 글자 바닥, 파란 점선(x높이 500), 위 회색선(대문자 높이 700)을 가이드로 씁니다. `→`/Enter 다음, `←` 이전, `Ctrl+Z` 되돌리기.
3. **미리보기**에서 방금 만든 폰트로 문장이 실시간 조판됩니다(직접 고쳐 쓸 수 있음).
4. **TTF 폰트 내려받기** → 더블클릭해 설치하면 워드·한글·포토샵 등에서 사용할 수 있습니다.

### 한글 자동 조합
- **+ 한글 기본 자모 24** 프리셋(ㄱㄴㄷㄹㅁㅂㅅㅇㅈㅊㅋㅌㅍㅎ ㅏㅑㅓㅕㅗㅛㅜㅠㅡㅣ)을 그리면 나머지 한글 음절을 자동으로 만듭니다. 범위는 전체 11,172자 / 자주 쓰는 2,350자(KS X 1001) / 끄기 중에서 고릅니다.
- 쌍자음·겹받침은 자음 두 개를 나란히, ㅐㅒㅔㅖ는 ㅏㅑㅓㅕ+ㅣ, ㅘㅙㅚㅝㅞㅟㅢ는 가로·세로 모음을 합쳐 만듭니다. 이런 자모를 직접 그리면 직접 그린 모양을 우선 씁니다.
- 음절은 모음 모양(세로·가로·섞임) × 받침 유무, 6가지 배치로 자모를 칸에 맞춰 넣습니다. 획은 중심선을 기준으로 늘리기 때문에, 작아져도 굵기가 거의 유지됩니다.
- 폰트에는 "자모×자리" 부품 글리프를 한 번씩만 넣고, 음절은 부품을 참조하는 TrueType 복합 글리프로 넣습니다. 11,172자 전체도 약 0.6 MB 정도입니다.
- **자리별 모양**: 같은 자모라도 자리마다 다른 모양을 그릴 수 있습니다. 예를 들어 초성 ㄱ은 '가·간·고·곤·과·관' 6자리, 받침 ㄱ은 '악·옥·왁' 3자리입니다. 패널에서 자모를 고르고 자리 칩을 누르면 필기 칸에 그 자리의 점선 상자와 예시 음절의 다른 자모가 연하게 나옵니다. 거기에 어울리게 쓰면, 쓴 위치와 크기 그대로 그 자리의 모든 음절에 쓰입니다. 안 그린 자리는 기본 모양을 상자에 맞춰 씁니다. 자리별 모양은 폰트에 글자로 들어가지 않고 조합에만 쓰이며, 템플릿 PDF로 인쇄해 스캔할 수도 있습니다(칸 안에 자리 상자가 점선으로 표시됨).
- 직접 쓴 음절이 있으면 그 음절은 직접 쓴 글씨가 우선합니다. 필기 칸과 글자 목록에서 자동 조합 결과는 파란색으로 표시됩니다.

### 종이에 써서 스캔하기
1. **템플릿 PDF 받기** — 지금 글자 목록으로 A4 템플릿(한 장 42칸)을 만듭니다. 칸 안의 연한 파란 선(테두리·기준선·x높이·대문자 높이)은 인식할 때 자동으로 지워집니다.
2. 검정 펜·사인펜으로 칸마다 한 글자를 씁니다.
3. **이미지 올리기** — 스캐너 이미지나 위에서 찍은 사진(JPG·PNG)을 여러 장 올립니다. 네 모서리 검은 네모로 원근을 펴고, 아래 점 줄(페이지 번호)로 몇 번째 장인지 자동 판별합니다.
4. 칸별 인식 결과를 확인하고(체크 해제 가능, 잉크 감도·회전·페이지 수동 조정) **폰트에 넣기**. 스캔한 글자도 필기 칸에서 덧그리거나 되돌릴 수 있습니다.

작업은 브라우저 localStorage에 자동 저장되고, `.json`으로 저장/불러오기 할 수 있습니다.

## 동작 원리
- 획은 폰트 단위(unitsPerEm 1000, ascender 800 / descender −200) 좌표 `[x, y, 굵기]` 로 기록합니다. 펜 입력이면 필압이 굵기에 반영됩니다.
- 획이 끝나면 떨림 보정(가중 이동평균) → Ramer–Douglas–Peucker 단순화.
- 각 꼭짓점은 원(2차 곡선 8개), 각 구간은 사다리꼴 외곽선으로 바꾸고, 모두 시계 방향으로 맞춰 겹쳐도(nonzero) 빈틈없이 칠해지게 합니다.
- 자체 TrueType 작성기가 `OS/2, cmap(format 4), glyf, head, hhea, hmtx, loca, maxp, name, post` 테이블과 체크섬을 직접 씁니다.
- 글자 폭: 자동(영문은 잉크 폭 + 양옆 여백, 한글·한자는 1000 정사각), 비례폭, 정사각 중 선택.

- 스캔: 모서리 기준점 검출(Otsu 이진화 + 연결 성분) → 4점 호모그래피 → 칸마다 200×200으로 펴서 이진화 → 픽셀 경계 추적 → 계단 완화·단순화 → 꺾인 곳은 실제 점, 나머지는 2차 곡선 제어점으로 외곽선 생성(바깥선 시계, 구멍 반시계).
- 템플릿 PDF는 JPEG 페이지를 담은 최소 PDF를 직접 써서 만듭니다.

## 한계
- 스캔은 종이 전체와 네 모서리 네모가 보여야 합니다. 심하게 구겨진 종이나 그늘진 사진은 잉크 감도로 보정해야 할 수 있습니다. PDF 스캔 파일은 이미지로 변환해서 올려 주세요.
- 자리는 모음 모양(세로·가로·섞임) × 받침 유무 기준으로만 나뉩니다. 상용 폰트처럼 "ㅏ 앞 ㄱ"과 "ㅓ 앞 ㄱ"까지 구분하지는 않으므로, 그래도 어색한 음절은 직접 써서 덮어써야 합니다.
- 스캔한 외곽선 자모는 조합할 때 크기와 함께 굵기도 줄어듭니다. 획으로 그린 자모는 굵기가 유지됩니다.
- BMP(U+0000–U+FFFF) 문자만 지원합니다(이모지 제외).
- 힌팅·커닝이 없고, 획이 겹친 외곽선을 그대로 둡니다(렌더링에는 문제없음).
