# igsave Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 폰에서 인스타그램/스레드 링크를 붙여넣거나 공유하면 미디어를 저장하는 PWA + Python 서버리스 API를 `igsave/`에 만든다.

**Architecture:** 정적 PWA(`index.html`)가 `/api/resolve`로 링크를 해석해 미디어 목록을 받고, `/api/download`로 허용된 CDN 파일만 프록시해 저장한다. 해석은 yt-dlp(영상/릴스)와 gallery-dl(사진/스레드)을 호출한다.

**Tech Stack:** Python 3 서버리스(Vercel), yt-dlp, gallery-dl, 바닐라 JS PWA, pytest.

**Spec:** `docs/superpowers/specs/2026-11-27-igsave-design.md`

## Global Constraints

- 허용 입력 도메인: `instagram.com`, `www.instagram.com`, `threads.net`, `www.threads.net`, `threads.com`, `www.threads.com` (https만).
- 허용 다운로드 호스트: 접미사 `cdninstagram.com`, `fbcdn.net`.
- 비공개·스토리·계정 일괄 다운로드는 지원하지 않는다.
- 실패는 반드시 사유 코드로 반환: `blocked`, `private_or_login`, `unsupported_url`, `not_found`.
- 폴더 `igsave/` 안에서만 작업한다. LFA 코어 규칙과 무관.

## Review Focus

- `https://evil.com/?u=instagram.com` 같이 도메인 문자열만 포함한 URL → `unsupported_url`.
- `/api/download`에 허용되지 않은 호스트(내부 IP, `localhost`) → 400.
- 쿼리스트링·트래킹 파라미터가 붙은 인스타 URL(`?igsh=...`) → 정상 해석.
- 여러 장 게시물 → 항목 전부 반환.
- 인스타가 서버를 막은 경우 → 빈 목록이 아니라 `blocked` 사유.

### Task 2: 미디어 해석기 (resolve)

**Files:**
- Create: `igsave/api/resolver.py`, `igsave/requirements.txt` (`yt-dlp`, `gallery-dl`)
- Test: `igsave/tests/test_resolver.py`

**Interfaces:**
- Consumes: `validate_post_url`
- Produces: `resolve(url: str) -> dict` — 성공 `{"ok": True, "items": [{"type": "image"|"video", "url": str, "thumb": str|None}]}`, 실패 `{"ok": False, "error": <사유 코드>}`. 내부 `_run_extractors(url) -> list[dict] | raises ExtractorError(reason)`는 외부 도구 호출 경계라 테스트에서 monkeypatch한다.

- [ ] **Step 1: 실패하는 테스트 작성** — monkeypatch로 (a) 여러 장 게시물 3항목 반환, (b) 429/로그인 필요 예외 → `blocked`/`private_or_login`, (c) 잘못된 URL → `unsupported_url`, (d) 결과가 CDN 허용 호스트가 아닌 항목은 제외.
- [ ] **Step 2: 실행해 실패 확인** — `python -m pytest tests/test_resolver.py -v`
- [ ] **Step 3: 구현** — 영상 URL이면 yt-dlp(`extract_info(download=False)`), 사진·스레드는 gallery-dl `--dump-json`. 예외 메시지에서 사유 코드를 매핑. 서버리스 시간 제한 내에 끝나도록 외부 호출 타임아웃 설정.
- [ ] **Step 4: 통과 확인**
- [ ] **Step 5: 커밋**
