# atomciv 생활 분자 → 발명 레시피 연결 — 짧은 설계

작성일: 2026-11-21 · 요청: "분자를 발명 레시피에도 연결해줘"

## 의도
2026-11-20에 추가한 생활 분자 14종이 도감에만 머물지 않게, 실제 쓰임새가 있는 발명의 재료로 쓴다.

## 결정
- 발명 8종을 추가한다. 시대 목표(ERAS.goal)는 그대로 둬서 기존 진행과 엔딩에는 영향이 없다.
- 각 발명 바로 앞에 재료 분자를 만드는 미션을 둔다. 힌트가 원자 개수를 알려 준다.
- 레시피는 모두 열 없이 섞기만 한다. 실제 화학과 역사에 근거한 **설계 조합표**다.

| 발명 | 재료 | 근거 |
|---|---|---|
| 🎨 동굴벽화 | 탄산칼슘 + 숯 | 선사 시대 흰·검정 안료 |
| 🏯 회반죽 | 수산화칼슘 + 모래 + 물 | 석회 모르타르, CO₂를 흡수해 CaCO₃로 굳음 |
| 🍾 탄산음료 | 탄산 + 유리 | 병에 가둔 CO₂ |
| 🕯️ 알코올램프 | 메탄올 + 유리 | 과학실 알코올램프 |
| ✨ 라이터 | 부테인 + 강철 + 부싯돌 | 부싯돌 휠 라이터 |
| 🧯 소화기 | 베이킹소다 + 아세트산 + 강철 | 산·알칼리식 소화기, CO₂ 거품 |
| 🚰 수돗물 | 차아염소산 + 물 | 수돗물 염소 소독 |
| 🌾 비료 | 요소 + 물 | 질소 비료 |

미션 위치는 석기(동굴벽화), 철기(회반죽, 탄산음료, 알코올램프), 산업(라이터, 소화기), 전기(수돗물, 비료) 시대다.
