# parking-game 3단계 — "주차 한 판" 정식 버전 설계

작성일: 2026-11-24 · 근거: 시험판 `parking-game/spike/day.html` (사용자가 직접 해 보고 "괜찮다" 확인)

## 의도
퀴즈형(2단계)은 "교육 프로그램 같다"는 반응이었다. 시험판에서 확인된 재미의 핵심을 정식 게임으로 만든다:
**지갑을 들고 하루를 돌며 → 직접 몰아서 세우고 → 눈에 보이는 단속원·주민을 보고 "잠깐은 괜찮겠지?"를 판단 → 볼일 보는 동안 빨리 감기 → 정산.**
법은 플레이 중에 설명하지 않고, 정산 한 줄과 하루가 끝난 뒤 펼쳐 보는 기록으로만 전한다.

## 시험판에서 이어받는 것 (검증됨)
- 조이스틱 하나 조작(밀면 그 방향, 뒤로 당기면 후진, 떼면 정지) + 자석 주차(3.5m 안에서 P → 자동 정렬)
- 매 판 무작위: 빈칸·주민 위치·머무는 시간
- 눈에 보이는 위험: 순찰하는 단속원, 시야를 돌리는 주민, CCTV 범위 → 1분 단위 시뮬레이션(숨은 주사위 없음)
- 시간제 칸은 허용 시간이 끝난 뒤부터, 정차만 되는 곳은 5분 뒤부터 위반
- 지갑 정산(보너스·지각·과태료·견인·스티커), 최고 기록

## 정식 버전에서 새로 하는 것 (작성자 제안 — 확인 대상)
1. **게임 시작 화면이 이 게임이 된다.** `parking-game/index.html` = 주차 한 판. 기존 판단 퀴즈·직접 운전 모드는 `parking-game/classic.html`로 옮기고 시작 화면 구석에 작은 링크만 둔다.
2. **3일 진행.** 1일차(마트·아파트·쇼핑몰·주택가·병원) → 2일차(전통시장·지하철역·강 건너 휴게소·고속도로 졸음쉼터) → 3일차(학교 앞 포함 섞어서, 더 붐비고 단속 잦음). 하루를 버티면 다음 날이 열린다(저장).
3. **운전 실력 보너스.** 자석 없이 칸 안에 반듯이 넣으면 +3,000원(자석은 그대로 쓸 수 있음).
4. **하루 끝 "오늘의 기록".** 장소별로 세운 곳·결과·쉬운 말 한 줄, 원하면 "근거 보기"로 조문 펼치기.
5. **효과음은 넣지 않는다**(2단계 비목표 유지). 진동은 휴대폰에서 지원되면 사고·과태료 순간에 짧게.

## 비목표
- 실제 지도, 온라인 순위표, 다른 차량 AI 주행

## 접근 방식
시험판 코드를 정리해 `parking-game/day.js`(게임)로 옮기고, 판정은 기존 `judge.js`·`rules.js`, 지도는 `levels.js`, 그리기는 `game.js`에서 렌더러를 `render.js`로 분리해 두 모드가 함께 쓴다. 정적 HTML + 바닐라 JS, 빌드 없음 유지. 시뮬레이션(단속 여부 계산)은 화면과 분리한 순수 함수로 두고 Node 테스트를 붙인다.

## 빌더에게 맡기는 것
- 장소별 순찰길·주민 자리 좌표, 단속 빈도·금액 밸런스(파산이 너무 잦지 않게)
- 3일차 난이도 올리는 방식(단속원 2명, 시간 단축 등)
