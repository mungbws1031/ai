# igsave — 인스타그램/스레드 미디어 저장 PWA (짧은 설계)

## 의도
폰에서 인스타그램(사진·릴스·동영상)과 스레드(짤) 링크를 붙여넣거나 공유 메뉴로 보내면 미디어를 폰에 저장한다. 공개 게시물, 개인 소장용.

## 목표 / 비목표
- 목표: 링크 → 미리보기 → 저장(여러 장 게시물 포함), 홈 화면 추가(PWA), 공유 대상(Share Target) 등록, 실패 사유를 화면에 표시.
- 비목표: 비공개 계정·로그인 필수 게시물, 스토리/하이라이트, 일괄 계정 크롤링, 재배포.
- 안티골: 서버가 막혀서 조용히 실패하는 것(반드시 사유를 보여준다).

## 접근 (사용자 선택: 1번)
1. 선택 — PWA + Python 서버(yt-dlp/gallery-dl)를 Vercel 등에 배포. 어디서든 사용, 단 클라우드 IP 차단 위험.
2. 집 PC 서버 + 터널 — 차단 덜 받음, PC 상시 가동 필요. (서버 코드를 그대로 재사용 가능하게 설계)
3. iOS 단축어/안드로이드 공유 — 기기별 제작 필요.

## 설계 (제 판단으로 정한 부분)
- 폴더 `igsave/`: `index.html`(단일 파일 PWA, 바닐라 JS) + `manifest.webmanifest` + `sw.js` + `api/`(Python 서버리스).
- `GET /api/resolve?url=` → yt-dlp(영상·릴스)/gallery-dl(사진·스레드)로 미디어 직링크 목록·썸네일 반환. 허용 도메인은 instagram.com, threads.net/threads.com만.
- `GET /api/download?u=` → 허용된 CDN 호스트만 프록시해 `Content-Disposition: attachment`로 스트리밍(SSRF 방지).
- 프런트: 붙여넣기 칸 + 공유 수신 → 카드 미리보기 → 개별/전체 저장. 폰은 Web Share API(파일)로 갤러리 저장 시도, 안 되면 일반 다운로드.
- 오류 문구: 차단(429/로그인 필요)·비공개·지원 안 하는 링크를 구분해 안내.
- 기술 선택(제 판단): Python 서버리스, 의존성 최소. LFA 코어 규칙과 무관한 독립 앱.

## 빌더에게 남기는 것
UI 세부 디자인, 에러 문구, 재시도 정책. 배포는 이 설계 승인 후 별도 확인.
