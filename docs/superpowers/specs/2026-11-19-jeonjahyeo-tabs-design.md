# 전자혀 하단 탭 정리 — 짧은 설계

- 작성일: 2026-11-19 · 대상: `cook/index.html` (+ 스토어 이미지)
- 상태: 승인 대기

## 의도
하단 탭 9개(탐색·계산·요리·소스·식단·냉장·보정·저장·감성)와 떠 있는 장바구니 버튼 때문에 요리 초보가 무엇을 눌러야 할지 헷갈린다(사용자: "탭이 너무 많아"). 장보기 전 "땡기는 맛 → 살 재료" 흐름이 바로 보이게 탭을 4개로 줄인다.

## 접근 방법
- **A. 탭 4개 + 더보기 (선택)** — 화면은 그대로 두고 버튼 위치만 옮긴다. 작업이 작고 위험이 적다. 가끔 쓰는 기능은 한 번 더 눌러야 한다.
- B. 비슷한 화면을 합쳐 탭 5개 — 숨기는 기능은 없지만 화면 안 하위 탭을 새로 만들어야 해 작업·변화가 크다.

사용자가 A를 골랐다.

## 결정된 것
- **하단 탭 4개:** `🍽️ 맛 고르기` · `🛒 장바구니` · `🧮 계산` · `☰ 더보기`
  - 맛 고르기 = 지금의 "감성" 화면. **앱을 켜면 이 화면이 먼저** 나온다.
  - 장바구니 = 지금의 장바구니 화면. 담긴 개수를 탭 위 작은 숫자로 보여준다.
  - 계산 = 지금의 "계산" 화면 그대로.
  - 더보기 = 새 목록 화면. 항목 7개: 요리 레시피 · 소스 · 식단 · 냉장고 · 맛 보정 · 저장한 배합 · 맛 그래프(지금의 "탐색"). 누르면 해당 화면으로 가고, 그 화면 위에 "← 더보기"로 돌아가는 줄을 둔다.
- 장바구니 탭이 생기므로 **떠 있는 장바구니 버튼은 없앤다**. "담았어요" 알림과 탭의 숫자로 대신한다.
- 다른 화면에서 다른 화면으로 넘어가는 기존 연결(예: 감성 → 계산, 레시피 → 요리, 식단 → 장바구니)은 그대로 동작해야 하고, 그때 하단 탭 강조는 그 화면이 속한 탭(더보기 안 화면이면 "더보기")에 켜진다.

## 목표 / 비목표
- 목표: 탭 4개, 첫 화면 맛 고르기, 기능 손실 0, 기존 테스트·계산 결과 불변(엔진 스냅샷 유지).
- 비목표(이번엔 안 함): 화면 내용 재설계, 앱 이름 통일("셰프 미강"/"전자혀" 제목 정리), 어려운 용어 바꾸기 — 다음 정리 후보로 남긴다.
- 반목표: 어떤 기능이든 들어갈 길이 없어지는 것; 장바구니에 담긴 개수를 알 수 없게 되는 것.

## 빌더에게 맡기는 것
- 더보기 화면의 모양(카드 목록 등, 기존 스타일 재사용), 탭 숫자 배지 모양.
- 기존 테스트가 탭 이름·`data-view`에 기대는 부분 수정, 새 테스트(탭 4개, 첫 화면, 더보기 7항목 이동, 숫자 배지, 화면 간 연결 시 탭 강조).
- 서비스 워커 캐시 버전 올리기, 스토어 스크린샷 4장 + 피처 그래픽 다시 만들기(`cook/app/scripts/screenshots.mjs`, `feature-graphic.mjs`).
