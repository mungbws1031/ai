# parking-game 2단계 — 초보운전자용 "여기 세워도 될까" 판단 연습 설계

작성일: 2026-11-17 · 대상 코드: `parking-game/` (1단계 프로토타입, 커밋 e9100ce)

## 1. 의도와 이유

초보운전자가 **운전하기 전에 집에서** 미리 연습하는 게임이다. 이들이 가장 궁금한 건
"들어갈 수 있을까"보다 **"여기 세워도 되나"**다. 성공은 실제 길에서 노면표시·연석 색·주변
시설(소화전, 정류장, 횡단보도, 모퉁이, 소방차 전용구역, 충전칸 등)을 보면
"주차 OK / 정차만 / 안 돼요 / 법은 괜찮지만 비매너"가 바로 떠오르는 상태다.

1단계 프로토타입은 핸들·페달 조작과 도로교통법 판정을 갖췄지만, 판정이 *세운 뒤에*
나오고 조작이 서툴면 판단 연습까지 가기 어렵다. 2단계는 판단을 중심에 놓는다.

## 2. 목표 · 비목표 · 반목표

**목표**
- 세우기 *전에* 답을 고르게 하고, 정답과 이유를 쉬운 말로 보여 준다.
- 초보운전자가 실제로 가는 네 장소를 쉬운 순서로 담는다: 마트 → 아파트 단지 → 병원 앞 → 학교 앞.
- 도로교통법 밖의 근거(소방기본법, 친환경자동차법, 장애인등편의법, 관리규정·매너)도 판정에 넣는다.
- 기본은 터치로 고르는 판단 모드, 같은 상황을 핸들·페달로 몰아 보는 "직접 운전" 모드를 함께 둔다.

**비목표**
- 실제 지도·GPS 연동, 특정 실존 매장·단지 재현.
- 움직이는 차량·보행자 AI, 효과음, 다국어, 회원·서버 저장.
- 운전 면허 시험 대비 문제은행.

**반목표 (기술적으로 돌아가도 실패)**
- 조문 번호와 과태료 숫자가 먼저 보여서 초보가 읽다 지치는 것.
- 조작이 어려워 판단 문제까지 못 가는 것 — 기본 모드에서 조작 실력이 필요하면 실패.
- 매너(법 아님)를 불법처럼, 또는 불법을 매너처럼 보여 주는 것. 네 답은 서로 섞이면 안 된다.
- 게임용 확률·대표 과태료를 실제 통계·확정 금액처럼 보여 주는 것.

## 3. 제약

- 정적 HTML + 바닐라 JS 유지. 빌드 없이 `index.html`을 열면 실행 (AGENTS.md: 자체 앱은 README에 스택 기록).
- 가로 화면 우선, 휴대폰 가로(약 844×390)에서 버튼·말풍선이 화면 안에 들어와야 한다.
- `judge.js`는 화면과 분리된 순수 함수로 유지하고 Node에서 테스트한다. 기존 22개 샘플 테스트는 계속 통과해야 한다.
- 법 근거는 구현 시 국가법령정보센터(law.go.kr)로 조문·금액을 다시 확인해 적는다. 지자체마다 다른 값은 "대표값"으로 표시한다.

## 4. 접근 방식 (검토한 것)

| 방식 | 내용 | 판단 |
|---|---|---|
| **A. 기존 코드 확장 (선택)** | `judge.js`·지도 렌더러 재사용, 규칙표에 법 분류와 4번째 답 추가, 레벨에 후보 자리·상황 카드 추가, 퀴즈 흐름을 화면 위에 얹고 핸들·페달은 "직접 운전" 모드로 유지 | 판정 테스트를 지키며 확장 가능, 파일만 열면 실행 유지 |
| B. 퀴즈 앱 따로 + 기존 게임 연결 | 판정 엔진만 공유, 화면 새로 | 렌더러·레벨 데이터 이중화, 두 모드 간 상황 연결 끊김 |
| C. React 등으로 재작성 | 화면 구조화 쉬움 | 현 규모에 과하고 빌드 단계가 생겨 "파일만 열면 실행" 상실 |

사용자가 "어떻게"는 맡겼고, A로 진행하기로 했다.

## 5. 결정된 사항 (사용자와 합의)

### 5.1 한 판의 흐름 — 판단 모드(기본)
```
[상황 카드] "마트 도착. 장보는 데 40분쯤 걸려요."
   ↓
[지도] 후보 자리 3~4곳 깜박임 (레벨이 정한 위치)
   ↓ 후보 터치
[질문] "여기 어때요?"  ( 주차 OK | 정차만 | 안 돼요 | 법은 OK·비매너 )
   ↓ 답 고르기
[차가 그 자리로 자동 이동] → 정답 공개 + 쉬운 말 이유 + (펼치면) 근거 조문·과태료
   ↓
틀렸거나 불법 자리면 "그대로 두면?" → 신고·CCTV·과태료·견인(또는 관리실 스티커·민원) 장면
```
- 한 레벨 안에서 후보 여러 개를 차례로 풀어 볼 수 있고, 마지막에 "실제로 어디에 둘래요?"로 하나를 골라 마무리한다.
- 기존 이야기 장치는 유지한다: 전화(상대가 늦음 → 5분 넘으면 주차로 바뀜), 신고하는 시민, CCTV.

### 5.2 직접 운전 모드
- 같은 레벨·같은 상황을 1단계의 핸들·페달·P R N D로 직접 몰아 세운다. P를 누르면 지금처럼 판정.
- 판단 모드에서 레벨을 연 뒤 버튼 하나로 전환한다.

### 5.3 네 가지 답과 근거 분류
| 답 | 의미 | 예 |
|---|---|---|
| 주차 OK | 오래 둬도 됨 | 주차구획, 백색 실선 가장자리 |
| 정차만 | 5분 이내 승하차·짐 싣기만 | 황색 점선, 병원 승하차 구역 |
| 안 돼요 | 법 위반 (과태료·견인 가능) | 소화전 5m, 어린이보호구역, 소방차 전용구역, 충전칸 일반차, 장애인전용 |
| 법은 OK·비매너 | 과태료는 없지만 곤란해짐 | 통로 이중주차, 경차·임산부 전용칸, 두 칸 걸침 |

규칙표의 각 항목에 `basis`(도로교통법 / 소방기본법 / 친환경자동차법 / 장애인등편의법 / 관리규정·매너)와 `answer`(위 4개 중 하나)를 추가한다.

추가할 규칙 (구현 시 조문·금액 재확인):
- 소방차 전용구역 — 소방기본법 제21조의2, 과태료 최대 100만원
- 전기차 충전구역 일반차 주차 — 친환경자동차법 제11조의2, 과태료 10만원
- 통로 이중주차 — 관리규정·매너 (기어 N·사이드브레이크 해제 안내)
- 경차·임산부·여성 우선칸 — 매너 (법적 강제 없음, 일부 지자체 조례)
- 두 칸 걸침 주차 — 매너
- 사유지 안내: 마트·아파트 주차장은 원칙적으로 도로교통법 주정차 단속 대상이 아니라는 설명

### 5.4 레벨 순서
1. **마트 주차장** — 차가 안 다님. 구획, 장애인전용, 전기차 충전칸, 경차·임산부칸, 통로.
2. **아파트 단지** — 소방차 전용구역, 통로 이중주차(N), 동 출입구 앞.
3. **병원 앞** — 실제 도로 시작. 승하차 정차, 응급차 진입로, 버스정류장, 황색 실선/점선.
4. **학교 앞** — 어린이보호구역(정차도 금지, 과태료 3배). 1단계 레벨 2를 다듬어 사용.
- 1단계의 카페 앞·골목 맛집은 "보너스" 레벨로 남긴다.

### 5.5 설명 말투
- 첫 줄은 쉬운 말 한 문장 + 이유. 예: "소화전 앞 5m는 잠깐도 안 돼요. 불 나면 소방차가 물을 못 써요."
- 근거 조문·과태료·신고 대상 여부는 "근거 보기"를 눌러 펼친다.

### 5.6 시간과 결과 화면
- 집에서 하는 연습이므로 레벨 제한시간은 기본 끔(설정에서 켤 수 있음). 이야기 속 "게임 시각"은 유지.
- 결과 화면은 점수보다 "다음엔 이렇게"(틀린 문제와 정답 이유)를 먼저 보여 준다.

### 5.7 사유지 경계 사례 (사용자 결정: A)
- 사유지 안 소화전 앞·출입구 앞처럼 도로교통법 과태료는 없지만 위험한 자리는 **"안 돼요"**로 가르친다.
- 근거 보기에는 "사유지라 도로교통법 과태료는 없음"을 정확히 적고, 실제 조치(관리실 경고·견인 요청, 소방차 전용구역이면 소방기본법 과태료)를 함께 보여 준다.

## 6. 설계 단계에서 정한 것 (검토 후, 작성자 판단 — 사용자 확인 대상)
- **정답은 자리에 고정**: "여기 어때요?"의 4개 답은 그 자리의 성질이다(황색 점선 = 정차만). 머무는 시간은 마지막 "실제로 어디에 둘래요?"에서만 반영한다(정차만 자리에 40분 → 불법 주차로 결과 처리). `judgePose`는 지금처럼 mode·minutes를 받고, 자리의 답은 규칙표 `answer`에서 읽는다.
- **전화 장치 일반화**: 모든 레벨에 "머무는 시간이 늘어나는 사건"을 둔다(마트: 장보기가 길어짐, 아파트: 친구 집 방문이 길어짐, 병원: 진료 대기, 학교: 상담 지연). 이미 푼 후보의 정답은 바뀌지 않는다.
- **기존 레벨 보존**: 학교 앞은 1단계 레벨 2를 복사해 새 레벨로 만들고, 원본 3개는 보너스로 그대로 둔다. 기존 22개 테스트는 수정 없이 계속 통과.
- **직접 운전 범위**: 새 4개 레벨 모두 직접 운전 가능(주차장 지도에도 출발점·입구 지정). 보너스 레벨은 운전 전용으로 두고, 판단 모드용 필드(`candidates`, `situation`)는 선택 필드로 한다.

## 7. 빌더에게 맡기는 것
- 후보 자리 표시 방식(깜박임, 번호 핀 등)과 답 버튼의 시각 디자인 — 기존 표지판 디자인 언어(파란 안내표지, 황색·적색) 안에서.
- 자동 이동 연출(차가 경로를 따라가는지, 순간 이동 후 페이드인지).
- 레벨별 정확한 지도 좌표·후보 개수(3~4개 범위), 매너 상황의 "결과 장면" 문구.
- 점수 계산식, 별 기준.
- 진행 저장은 브라우저 `localStorage`(실패해도 동작).
- 판정 테스트: 새 규칙과 레벨마다 `samples`(후보 자리 = 테스트 케이스)를 추가.
