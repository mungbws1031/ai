# 전자혀 첫 화면 "오늘 뭐 먹을까요?" — 짧은 설계

- 작성일: 2026-11-27 · 대상: `cook/index.html` (맛 고르기 첫 화면)
- 상태: 승인 대기

## 의도
사용자: "첫 화면부터 뭘 할지 정하게 해줘." 지금 첫 화면은 찾기·추천 목록·👶·🏆·맛 카드 20여 개가 한꺼번에 있어 막막한 초보(아이 거절로 위축된 부모)가 오히려 멈춘다. 앱을 열면 **질문 몇 개에 답하면 앱이 오늘 요리 하나를 정해 주는** 화면이 맨 위에 있어야 한다.

## 접근 방법
- **A. 질문 몇 개 → 요리 하나 추천 (선택)** — 고르는 부담을 앱이 대신 진다.
- B. 큰 버튼 3~4개로 길만 나눔 — "모르겠어요"를 눌러도 또 골라야 한다.
사용자가 A를 골랐다.

## 결정된 것
- 맨 위 카드 `오늘 뭐 먹을까요?` — 질문을 **한 번에 하나씩**(점 3개 진행 표시), 버튼 한 번 누르면 다음 질문.
  1. `오늘 누구랑 먹어요?` — `👶 아이랑` / `🙋 혼자` / `👨‍👩‍👧 가족 다` → 인분 기본값 2 / 1 / 4, 아이랑이면 `kid:true` 요리만.
  2. `시간은 얼마나 있어요?` — `⚡ 15분` / `⏱ 30분` / `🍲 넉넉해요` → 요리 시간 ≤15 / ≤30 / 제한 없음.
  3. `매운 거 괜찮아요?` — `🙅 안 매운 거` / `🌶 좋아요`. **아이랑을 골랐으면 이 질문은 건너뛴다**(안 매운 것으로).
- 결과: `오늘은 이거 어때요?` + 요리 카드(이모지·이름·`🍳 난이도 비유 · ⏱ 시간`, 아이랑이면 아이 팁 한 줄) + 버튼 `이걸로 할게요` (만드는 법을 고른 인분으로 열기) · `다른 거 보기` (겹치지 않게 다음 후보) · `처음부터`.
- 고르는 법(빌더 결정 가능한 세부는 아래): 후보는 요리 사전(HOME_DISHES) 중 조건에 맞는 것. 난이도 낮은 것(1 → 2 → 3)을 먼저, 같은 난이도 안에서는 무작위. "아이가 안 먹었어요"로 기록된 요리는 뒤로 미룬다. 맞는 게 없으면 시간 조건부터 풀고 `조건을 조금 넓혀서 골랐어요` 한 줄을 보인다.
- 매운 요리 판단: 재료에 고춧가루·고추장·청양고추·두반장·고추기름·페페론치노·김치가 있으면 매운 요리.
- 지난번 답을 기기에 기억해 두고, 다음에 열면 질문 위에 `지난번처럼(아이랑 · 30분) 바로 골라 줘` 버튼 하나.
- 아래쪽: `먹고 싶은 게 있어요?` 찾기 칸(지금 그대로), 🏆 우리 집 성공 요리, 👶 바로가기, 그 아래 `또는 땡기는 맛으로 고르기` 맛 카드. 맨 위 카드가 대신하므로 **"처음이라면" 추천 목록은 뺀다**.

## 목표 / 비목표 / 반목표
- 목표: 앱을 열고 3번 이내로 눌러 오늘 요리가 정해지고, 1번 더 누르면 만드는 법이 열린다.
- 비목표: 냉장고 재료로 고르기, 영양·식단 추천, 로그인.
- 반목표: 질문이 4개 이상으로 늘어 또 부담이 되는 것, 아이랑인데 매운 요리가 나오는 것, 같은 요리만 계속 나오는 것, 아이 탓·사용자 탓 문구.

## 빌더에게 맡기는 것
