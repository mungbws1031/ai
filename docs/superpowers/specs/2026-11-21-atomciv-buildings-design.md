# atomciv 건물·지형 — 지도에 직접 세우기 (짧은 설계)

작성일: 2026-11-21 · 상태: 승인됨 (사용자: "A" → "응")

## 의도
아이가 물건(발명)만 모으는 데서 그치지 않고, 건물과 지형을 직접 지도에 세워 "내 문명"을 꾸미게 한다.

## 접근 방식
- **A (선택):** 그릇에서 만든 건물을 지도에서 아이가 칸을 골라 세운다. 지형도 바뀐다.
- **B:** 발명처럼 자동으로 세운다. 놀이가 지금과 같아서 뺐다.

## 결정
- **섬 넓히기:** MAP_RADIUS를 6에서 8로 바꾼다. 땅은 7번째 고리까지다.
  - 칸 크기는 그대로 두고 지도 영역을 손가락으로 밀어서 본다.
  - 지도를 열면 수도가 가운데 오도록 스크롤한다.
- **건물 데이터:** 건물은 ITEMS에 `build: { site, change? }`를 붙인다. 고정 타일(MAP_TILES)은 없다.
- **세우는 순서:**
  1. 건물을 만들면 카드에 [지도에 세우러 가기] 버튼이 나온다.
  2. 지도가 "세우기 모드"로 열리고, 세울 수 있는 칸이 반짝인다.
  3. 칸을 누르면 세워진다.
- **아직 안 세운 건물:** 지도 위에 칩으로 보여서 나중에 세울 수 있다.
- **site 종류:**

| site | 세울 수 있는 칸 |
|---|---|
| land | 물이 아닌 칸 |
| grass | 풀밭·평야 |
| hills | 언덕 |
| river | 강 |
| water | 물 (우리 땅이거나 우리 땅과 맞닿은 칸) |
| coast | 물과 맞닿은 땅 |

  - 공통 조건: 우리 땅이고, 비어 있는 칸이어야 한다. 발명 칸·수도·다른 건물이 있으면 비어 있지 않은 것이다.
  - water는 예외로 우리 땅과 맞닿기만 해도 된다.
  - 맞는 칸이 하나도 없으면 비어 있는 우리 땅 아무 데나 허용한다. 아이가 막히지 않게 하기 위해서다.
- **지형 바꾸기 (change):**
  - farm: 그 칸이 논밭이 된다.
  - lake: 옆의 풀밭·평야가 물이 된다 (댐).
  - land: 물이 평야가 된다 (간척지).
- **영토:** 세운 건물도 발명처럼 주변 칸을 영토로 만든다. 그래서 다리를 놓으면 건너편 땅이 열린다.
- **강 칸:** 강이 무작위 지형에도 생기도록 해서 댐·다리를 세울 곳이 있게 한다.
- **저장:** `state.placed`에 {건물 id: [q, r]}로 저장하고 파일 저장·불러오기에도 넣는다.
- **진행:** 시대 목표는 그대로 둔다. 건물 미션은 각 시대 끝에 붙는다. 미션은 건물을 만들면 완료되고, 세우기는 권장 사항이다.
