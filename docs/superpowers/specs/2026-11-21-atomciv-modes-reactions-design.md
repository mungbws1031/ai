# atomciv 난이도 모드 + 반응 순서 + 첫 분자 팁 — 짧은 설계

작성일: 2026-11-21 · 상태: 승인됨 (사용자: "응")

## 의도
- 첫 분자 만들기를 쉽게 하는 팁이 필요하다.
- 쉬움·보통·어려움 모드를 만든다. 어려움은 정말 어렵게 한다.
- 실제 화학처럼 먼저 만들어야 하는 분자(반응 순서)를 반영한다.

## 접근 방식
- **A (선택): 반응 순서를 모드에 따라 다르게 적용한다.**
  - 쉬움: 반응 순서를 무시한다.
  - 보통: 원자로 직접 만들어도 인정하고 반응식을 보여 준다.
  - 어려움: 반응으로만 만들 수 있다.
- **B: 모든 모드에서 반응으로만 만들기.** 초등학생이 막히기 쉬워서 뺐다.

## 모드별 차이 (승인된 표)

| | 쉬움 | 보통 | 어려움 |
|---|---|---|---|
| 첫 분자 미션 (H₂, H₂O, O₂) | 단계 팁 + 💡을 누르면 필요한 원자를 실험대에 올리고 👆 손가락이 끌 길을 보여 줌 | 단계 팁 | 없음 |
| 💡 힌트 | 무제한 | 무제한 | 미션당 3번 |
| 반응 순서 | 무시 | 원자로 만들어도 인정하고 반응식을 보여 줌 | 반응으로만 인정 |
| 서랍의 손 개수 점 | 보임 | 보임 | 숨김 |

## 반응 (그릇에서 분자 → 분자, 부산물은 설명에만)

| 반응 | 부산물 |
|---|---|
| CaO + H₂O → Ca(OH)₂ | |
| Ca(OH)₂ + CO₂ → CaCO₃ | H₂O |
| CO₂ + H₂O → H₂CO₃ | |
| NaOH + CO₂ → NaHCO₃ | |
| Cl₂ + H₂O → HOCl | HCl |
| NaOH + Cl₂ → NaOCl | NaCl, H₂O |
| NH₃ + CO₂ + 🔥 → 요소 | H₂O |
| MgO + H₂O → Mg(OH)₂ | |

- Cl₂(염소 기체) 분자를 새로 추가한다.
- 위 반응으로 만들어지는 분자는 보통·어려움 모드에서 힌트가 반응 재료를 안내한다.
- 미션 순서를 고쳐 반응 재료 분자를 먼저 만들게 한다.
  - 석기: CaO → Ca(OH)₂ → CaCO₃ → 동굴벽화
  - 산업: NaOH → 베이킹소다
  - 전기: Cl₂ → 차아염소산

## Claude가 정한 것
- **난이도 고르는 화면:** 저장이 없는 첫 실행 때 카드로 고른다. 💾 패널에서 바꿀 수 있다.
- **기존 저장:** mode가 없으면 보통으로 본다.
- **저장 파일:** 파일 저장·불러오기에 mode를 포함한다.
- **그릇 자동 넣기:** 분자를 그릇에 자동으로 넣는 것은 두 경우뿐이다. 기존 재료 분자(물, 모래, 소금)이거나, 지금 미션의 힌트에 있는 분자일 때다. 이산화탄소처럼 초반에 만드는 분자가 갑자기 그릇에 들어가지 않게 하기 위해서다.
- **👆 길 안내 규칙:** 남은 손이 가장 적은 원자에서, 손이 가장 많이 남은 다른 원자로 가는 길을 보여 준다.
