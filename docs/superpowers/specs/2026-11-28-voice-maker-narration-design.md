# 목소리 공방 — 내레이션 작업실 설계 (A+B)

## 목적
영상 내레이션·이야기 내레이션을 **원고 → 완성 오디오 파일**로 만든다. 지금 앱은 글 읽기 음성을 파일로 못 남기고, 녹음 변조는 한 번에 한 토막뿐이라 내레이션 한 편을 만들 수 없다.

## 고른 방식
| 안 | 내용 | 장단점 |
|---|---|---|
| A. 직접 녹음 작업실 | 문장별 녹음 + 캐릭터·EQ → 한 파일로 잇기 | 무료·기기 안에서만. 품질은 녹음에 좌우 |
| B. AI 음성 연결 | ElevenLabs API 키로 문장을 AI 음성 생성 | 가장 자연스러움. 글자 수만큼 유료, 원고가 외부로 감 |
| C. 앱 수정 없이 Claude가 생성 | 연결된 Magnific으로 파일 생성 | 한두 편엔 빠름, 반복 사용 불편 |

**선택: A+B (사용자 결정).** 한 작업 화면에서 줄마다 "직접 녹음" 또는 "AI 음성"을 고른다.

## 목표
- 원고를 붙여 넣으면 문장(줄) 단위로 나뉜다. 줄을 합치고 나누고 고칠 수 있다.
- **목소리(화자)** 를 여러 개 만든다: 내레이터, 등장인물 등. 화자마다 높이·메아리·공기·비음·EQ, AI 음성 선택을 저장한다. 줄마다 화자를 고른다.
- 줄마다 소스: 직접 녹음(마이크/파일) 또는 AI 생성. 줄 단위로 미리듣기·다시 하기.
- 줄 뒤 쉼(기본 0.4초, 문단 끝 0.9초) 조절.
- **내보내기**: 전체를 한 개의 WAV로(화자별 효과 적용) + **자막 SRT**(영상 편집기에 바로 올리게, 줄 시작·끝 시각).
- 작업이 새로고침·앱 재실행 후에도 남는다(원고·설정은 localStorage, 녹음·생성 오디오는 IndexedDB).

## 하지 않을 것
- 배경음악·영상 편집, 앱 안에서 목소리 복제, 클라우드 동기화·로그인, 여러 프로젝트 관리(한 번에 작업 하나, "새로 시작"만).

## 실패로 보는 것
- 사용자가 모르는 사이에 요금이 나가는 것 → AI 생성 전에 **글자 수와 생성할 줄 수를 보여주고 확인**받는다. 글·화자가 안 바뀐 줄은 다시 생성하지 않는다(캐시).
- API 키가 ElevenLabs 말고 다른 곳으로 가는 것. 키는 이 기기 localStorage에만, 화면엔 가려서 표시, "키 지우기" 제공.
- 녹음이 외부로 나가는 것(직접 녹음 줄은 절대 업로드 안 함).

## 제약
- 기존처럼 단일 `index.html` PWA, 빌드 도구·서버 없음. 기존 효과 엔진(`buildGraph`)을 화자별로 재사용.
- AI: ElevenLabs `POST /v1/text-to-speech/{voice_id}`(모델 `eleven_multilingual_v2`, 한국어 지원), 목소리 목록 `GET /v1/voices`, 남은 글자 수 `GET /v1/user/subscription`. 브라우저에서 직접 호출(CORS 허용 여부는 구현 첫 단계에서 확인, 막히면 사용자에게 알리고 C 경로 안내).
- 오프라인이면 AI 줄은 "인터넷 연결 필요"로 표시, 녹음 줄은 그대로 동작.

## 화면(제안)
```
[글 → 목소리] [내 목소리 바꾸기] [내레이션]
┌ 원고 붙여넣기 ───────────────┐  ┌ 목소리(화자) ─────────┐
│ ... [줄로 나누기]             │  │ ● 내레이터  AI: 지수   │
└──────────────────────────────┘  │ ● 토끼      녹음+헬륨  │
 1 [내레이터▾] 옛날 옛적에…  [AI|녹음] ▶ ⟳  쉼 0.4s │ + 목소리 추가 / 편집  │
 2 [토끼▾]    "나 먼저 갈게!" [녹음 ●]  ▶ ⟳         └ AI 설정: API 키, 남은 글자 ┘
 …
[빈 줄 AI로 모두 생성 (1,240자)]  [전체 듣기]  [WAV 저장] [자막 SRT 저장]
```
화자 편집은 기존 '내 목소리 바꾸기' 컨트롤(높이·메아리·공기·비음·EQ)을 그대로 쓴다.

## 빌더에게 맡기는 것
- 문장 분리 규칙 세부, IndexedDB 스키마, 줄 상태 표시 디자인, 전체 듣기 중 현재 줄 강조 방식.
- 테스트: 기존 회귀 테스트에 내레이션 탭 추가. AI 호출은 Playwright `route`로 가짜 응답(실제 키·요금 없이).

## 내가 정한 것(확인 부탁)
1. 새 탭 "내레이션"으로 넣고 기존 두 탭은 그대로 둔다.
2. AI 서비스는 ElevenLabs 하나만(한국어 품질·목소리 수). 다른 서비스는 나중에.
3. 자막 SRT 내보내기를 포함한다(영상 내레이션용).
4. 출력은 WAV만(MP3 인코더는 용량 커서 제외).
