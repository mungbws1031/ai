# atomciv 산업시대 추가 — 짧은 설계

작성일: 2026-11-19 · 상태: 승인됨 (사용자: "응 그대로 진행해줘")
기반: `docs/superpowers/specs/2026-11-18-atomciv-design.md` §8

## 의도
철기시대 다음 시대를 한 번에 하나씩 붙인다. 첫 번째는 산업시대다. 1단계에서 만든 분자(물, 모래, CO₂)가 다시 쓰여서 "원자에서 문명까지"가 이어지는 느낌을 강화한다.

## 접근 방식
- **기존 데이터 구조를 확장한다 (선택):** ITEMS, RECIPES, ERAS, MISSIONS, VILLAGE에 항목을 추가한다. 코드 구조는 바꾸지 않는다.
- **네 시대를 한꺼번에 추가하는 안은 제외했다.** 아이 반응을 보며 한 시대씩 늘리기로 했다.

## 내용 (사용자 승인)
- **새 자연 재료:** 석탄 `coal` ⚫, 석회석 `limestone` 🪨
- **레시피:**
  - H2O + 🔥 → `steam` 수증기 ♨️
  - iron + coal + 🔥 → `steel` 강철
  - steel + steam → `steam_engine` 증기기관
  - steam_engine + steel → `train` 기차 🚂
  - limestone + 🔥 → `quicklime` 생석회
  - quicklime + clay + 🔥 → `cement` 시멘트
  - cement + O2Si + H2O → `concrete` 콘크리트 🧱
- **시대 목표:** steel, steam_engine, train, concrete
- **미션:** 위 7개 발명을 레시피 순서대로 추가한다.
- **마을 배경:** 공장 굴뚝, 철로, 기차가 있는 산업 도시
- **엔딩 카드:** 🏆 완성 카드는 마지막 시대(산업)를 마친 뒤에 나온다.

## Claude가 정한 것
- **엔딩 카드 다시 보이기:** 철기시대를 이미 끝낸 아이도 산업시대를 마치면 엔딩 카드를 다시 볼 수 있어야 한다. 그래서 저장값을 `allDone`(참/거짓) 대신 "엔딩을 본 시대 수"(`endingEras`)로 바꾼다. 엔딩 문구는 "{마지막 시대}까지 완성!"으로 만든다.
- **기술 지도 칸 배치:** 시대 칸 수가 늘어도 깨지지 않게 자동으로 배치되는 격자로 바꾼다.
- **"왜 그럴까?" 문구:**
  - 강철: "철에 탄소를 아주 조금 섞으면 더 단단하고 질겨져!"
  - 생석회: "석회석을 구우면 이산화탄소가 빠져나가!"
  - 콘크리트: "시멘트가 물과 반응해서 모래를 꽉 붙잡고 굳어!"
  - 수증기: "물이 끓어 수증기가 되면 부피가 엄청 커져서 밀어내는 힘이 생겨!"
- **석탄과 숯의 관계:** 석탄도 숯처럼 탄소가 많다고 설명한다. 철(iron) 레시피는 숯을 그대로 쓴다.
