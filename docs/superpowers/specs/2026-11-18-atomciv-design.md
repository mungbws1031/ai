# 원자에서 문명까지 (atomciv) — 설계 문서

작성일: 2026-11-18 · 상태: 승인 대기

## 1. 의도와 이유

초등학생이 집에서 태블릿으로 **혼자** 하는 게임. 원자를 조합해 분자를 만들고, 분자로 물질을,
물질로 발명품을 만들어 석기시대부터 현대 문명까지 올라간다. 정해진 조합표를 외우는 게임이 아니라
**진짜 과학 규칙이 결과를 정하고, 그 이유를 아이 눈높이로 보여 주는 것**이 핵심이다.

## 2. 목표 / 비목표 / 실패 조건

**목표**
- 어른 설명 없이 아이 혼자 규칙을 깨닫는다 (손 개수 = 원자가).
- 만들 때마다 "왜 그럴까?" 카드로 진짜 과학을 한 줄씩 배운다.
- 문명이 커지는 게 눈에 보여서 계속하고 싶어진다.

**비목표 (1차 버전)**
- 전체 시대 완성 (1차는 철기시대까지 한 갈래).
- 반응 속도·화학 평형 같은 정량적 시뮬레이션.
- 계정, 서버, 멀티플레이, 광고, 결제.

**실패 조건 (작동해도 실패)**
- 글을 많이 읽어야 진행되는 경우.
- 틀린 과학을 사실처럼 가르치는 경우 (단순화는 OK, 거짓은 안 됨).
- 벌점·게임오버로 아이가 좌절하는 경우.
- 기존 원소 조합 게임의 이름·그림·조합표를 베낀 것처럼 보이는 경우.

## 3. 제약

- 태블릿 브라우저 (iPad Safari, 안드로이드 Chrome), 가로·세로 모두 지원, 터치 우선.
- 오프라인 동작, 진행 상황은 기기에 저장 (localStorage).
- 단일 HTML 파일, 외부 라이브러리 없이 동작.
- 이 저장소의 독립 앱 규칙을 따름: 최상위 `atomciv/` 폴더, 자체 README.

## 4. 접근 방식 (검토한 안)

| 안 | 내용 | 장단점 |
|---|---|---|
| **A. 단일 HTML PWA (선택)** | `scent-mixer/`처럼 파일 하나 + manifest/service worker | 링크 하나로 바로 설치, 오프라인 가능, 고치기 빠름. 화려한 3D는 어려움 |
| B. Vite + React PWA | `miri/` 방식 | 커져도 관리 쉬움, 빌드 필요 |
| C. 앱스토어 앱 (Unity 등) | 네이티브 | 효과가 가장 화려함, 개발·배포가 매우 김 |

**사용자 선택: A.** 이유: 아이 반응을 보며 빠르게 고치기 좋음. 커지면 B로 옮긴다.

## 5. 사용자가 정한 것

- 대상: 초등학생, 집에서 태블릿으로 혼자.
- 진행: 원자 → 분자 → 물질 → 발명 → 시대, 최신 문명까지.
- 만드는 방식: A (단일 HTML).
- 문명 표시: 기술 지도 기본 + 시대마다 바뀌는 배경 마을 그림 (시대당 한 장).

## 6. 게임 설계 (Claude 제안, 수정 가능)

### 6.1 화면 구성
```
┌───────────────────────────────────────────┐
│ 🏛 철기시대   [미션] [실험실] [도감] [지도] │  ← 상단 탭
├─────────────┬─────────────────────────────┤
│ 재료 서랍    │        실험대                │
│ (H)(O)(C)   │    [H]─(O)─[H]               │
│ (N)(Na)(Cl) │       ✨ 물 완성!             │
│ 💧 🪨 🔥     │                             │
├─────────────┴─────────────────────────────┤
│  배경: 시대별 마을 그림 (시대가 바뀌면 교체)    │
└───────────────────────────────────────────┘
```

### 6.2 1단계 — 원자 → 분자 (진짜 규칙으로 판정)
- 원자는 "손 달린 캐릭터". 손 개수 = 원자가: H 1, O 2, N 3, C 4, Cl 1, Na 1.
- 실험대에 원자를 끌어 놓고, 두 원자를 서로 가까이 대면 손 하나씩 잡음 (단일결합).
  같은 쌍을 한 번 더 이으면 이중결합, 한 번 더 이으면 삼중결합 (손 1개씩 추가 사용).
- **판정 규칙:** 실험대 위 원자 묶음의 모든 손이 다 잡혔으면 → 분자 완성.
  그 묶음의 분자식(원소별 개수)을 사전에 찾아서
  - 있으면: 이름 + 그림 + "왜 그럴까?" 카드 + 도감 등록.
  - 없지만 규칙은 맞으면: "규칙은 맞지만 아직 이름 모르는 분자!" (보너스 반짝임, 도감엔 미등록).
- 손이 남으면 원자가 흔들리며 빈 손 강조. 실패 페널티 없음.
- Na–Cl은 예외 연출: "Na가 전자를 Cl에게 줘 버려!" → 이온결합(소금). 전기음성도는 "욕심" 성격으로만 표현.
- 1차 분자 목록: H₂, O₂, N₂, H₂O, CO₂, CH₄, NH₃, HCl, NaCl, CO (C=O 삼중결합 표현은 단순화하여 허용 여부는 빌더 판단).

### 6.3 2~4단계 — 물질·발명·시대 (설계된 조합표)
- 여기부터는 실제 과학·역사 기반으로 **설계한 레시피**. 문서와 게임 안에서 이를 숨기지 않는다.
- 재료 서랍의 아이템 2~3개 + 선택적 🔥(열)을 실험대에 올리면 레시피 일치 시 생성.
- 1차 범위 (철기시대까지 한 갈래, 예시):
  - 물질: 모래(SiO₂ — 규소+산소 2), 석회석, 철광석, 숯(탄소), 점토, 구리광석, 주석광석
  - 발명: 돌도끼 → 불 → 토기(점토+🔥) → 구리(구리광석+숯+🔥) → 청동(구리+주석) → 철(철광석+숯+🔥) → 유리(모래+🔥)
  - 시대: 석기 → 청동기 → 철기. 핵심 발명을 모으면 다음 시대 해금 + 배경 마을 교체.
- 모든 발명에 "왜 그럴까?" 카드 1~2문장 (예: "숯 속 탄소가 철광석에서 산소를 빼앗아 가서 철만 남아!").

### 6.4 모드
- **미션:** 목표 하나씩 ("물을 만들어 봐"). 첫 미션들이 튜토리얼 역할. 막히면 힌트 버튼 → 필요한 원자가 반짝.
- **실험실:** 자유 조합. 우연한 발견 시 "새 발견!".
- **도감:** 만든 것 모음, 카드 다시 보기.
- **지도:** 시대별 기술 지도, 발명품마다 불이 켜짐. 화면 하단 배경 마을은 시대가 바뀔 때 교체.

### 6.5 연출과 접근성
- 큰 터치 영역(최소 56px), 글은 한 줄 이내, 아이콘·그림 우선.
- 결합 시 "딸깍" 효과음 + 반짝임 (음소거 버튼).
- 그림은 SVG/CSS로 직접 그림 (외부 에셋 없음).

## 7. 빌더에게 맡기는 것 / Claude가 정한 것

- 저장 키 이름, 파일 내부 구조, 레시피 데이터 형식(JS 객체 배열).
- 각 분자·발명의 정확한 그림과 카드 문구 (과학적으로 틀리지 않게, 초등 어휘로).
- 이중·삼중결합 조작 UX의 세부 동작.
- 확인 방법: Playwright로 태블릿 크기(iPad 가로/세로)에서 미션 1~3 진행 스크린샷 확인.
