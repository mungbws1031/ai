# DocBox · 개인용 웹 문서함

클라우디움(문서중앙화) 같은 "내 문서를 한곳에 모아 두고, 버전·검색·복구까지 되는" 기능을 **혼자 쓰는 용도**로 줄인 웹앱입니다.
Python 표준 라이브러리만 사용하므로 **설치할 패키지가 없습니다** (Python 3.10 이상).

## 실행

```bash
cd docbox
python3 server.py
# 브라우저에서 http://127.0.0.1:8765
```

휴대폰 등 같은 와이파이의 다른 기기에서도 쓰려면 **반드시 비밀번호를 설정**하세요.

```bash
DOCBOX_PASSWORD='나만아는비번' python3 server.py --host 0.0.0.0
# 다른 기기에서 http://<이 PC의 IP>:8765
```

Windows PowerShell:
```powershell
$env:DOCBOX_PASSWORD='나만아는비번'; python server.py --host 0.0.0.0
```

| 환경 변수 | 설명 | 기본값 |
|---|---|---|
| `DOCBOX_PASSWORD` | 설정하면 로그인 화면이 생김 | 없음 (로그인 없음) |
| `DOCBOX_DATA` | 문서가 저장될 폴더 | `docbox/data/` |
| `DOCBOX_MAX_MB` | 파일 1개 최대 크기 | 500 |

## 기능

| 클라우디움 기능 | DocBox |
|---|---|
| 문서 중앙 저장 | 드래그&드롭 / 업로드 버튼 → `data/` 한곳에 저장 |
| 폴더 체계 | 하위 폴더 무제한, 문서를 폴더로 끌어다 놓아 이동 |
| 버전 관리 | 같은 폴더에 **같은 이름으로 다시 올리면 v2, v3…** 로 쌓임. 예전 버전 다운로드 · "되돌리기" |
| 검색 | 파일명 · 태그 · 버전 메모 · **텍스트 문서 본문**(txt, md, csv, json 등) |
| 삭제 복구 | 휴지통 → 복원 / 영구 삭제 |
| 미리보기 | 이미지 · PDF · 동영상 · 음성 · 텍스트 |
| 기타 | 태그, 즐겨찾기, 사용량 표시, 다크 모드, 모바일 화면 |

같은 내용의 파일은 한 번만 저장됩니다(SHA-256 중복 제거).

## 데이터 구조 & 백업

```
data/
├── docbox.sqlite3     # 폴더·문서·버전·태그 정보
└── blobs/ab/abcd…     # 원본 파일 (내용 해시 이름)
```

**백업은 `data/` 폴더를 통째로 복사**하면 됩니다. 랜섬웨어 대비가 목적이라면 외장 디스크나 다른 클라우드에 주기적으로 복사해 두세요.

## 한계 (개인용으로 줄인 부분)

- 1인용입니다. 사용자/권한 관리, DRM, 반출 통제(DLP)는 없습니다.
- PC 폴더 자동 동기화는 없습니다. 직접 업로드해야 합니다.
- HWP·DOCX·PDF **본문** 검색은 지원하지 않습니다(파일명·태그로 검색).
- 인터넷에 공개하려면 HTTPS(리버스 프록시, Tailscale 등) 뒤에 두세요. 이 서버 자체는 HTTP만 제공합니다.
