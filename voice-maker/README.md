# 목소리 공방 (voice-maker)

글을 목소리로 읽어주고, 내 목소리를 캐릭터 목소리로 바꿔 WAV로 저장하는 단일 파일 PWA. 서버·API 키·가입 없이 브라우저만으로 동작합니다.

## 실행
```bash
cd voice-maker
python3 -m http.server 8000   # http://localhost:8000
```
마이크 녹음은 `localhost` 또는 `https`에서만 허용됩니다.

## 기능
- **글 → 목소리**: 브라우저 내장 음성(Web Speech API)으로 읽기. 목소리 선택, 빠르기·높낮이·크기, 캐릭터 프리셋(아나운서·꼬마·할아버지·로봇·다람쥐·자장가), 자주 쓰는 문장 저장(localStorage). 긴 글은 문장 단위로 나눠 읽음.
  - 한계: 브라우저 정책상 이 음성은 파일로 저장할 수 없음.
- **내 목소리 바꾸기**: 마이크 녹음(최대 60초) 또는 오디오 파일 불러오기 → 효과(헬륨·거인·로봇·무전기·동굴·외계인·거꾸로) + 높이·메아리 조절 → 미리듣기 → `OfflineAudioContext`로 렌더링해 **WAV 저장**. 모든 처리는 기기 안에서만.
- **음색 미세조정**: ‘공기 섞인 소리’(목소리 크기를 따라가는 숨소리 노이즈), ‘비음 섞인 소리’(1k·2.6kHz 공명 강조 + 저역·고역 감쇠) 슬라이더와 프리셋(숨소리·콧소리). **7밴드 이퀄라이저**(100Hz~8kHz, ±12dB) + 응답 곡선 표시, 재생 중 조절하면 바로 반영. 출력단에 리미터.
- **내레이션**: 원고 → 문장·대사 단위 줄 → 줄마다 목소리(화자)와 만드는 방식(직접 녹음 / ElevenLabs AI) 선택 → 줄 미리듣기 → 쉼 조절 → **전체 WAV + 자막 SRT** 저장.
  - 화자마다 캐릭터 효과·EQ(‘내 목소리 바꾸기’ 설정 가져오기)와 AI 목소리를 저장. 화자 삭제 시 그 줄은 내레이터로.
  - AI: API 키는 이 기기 localStorage에만, 생성 전 줄·글자 수 확인, 글·목소리가 안 바뀐 줄은 재생성하지 않음. 401·한도·연결 실패는 원인별 안내.
  - 원고·설정은 localStorage, 녹음·AI 오디오는 IndexedDB(`voice-maker`)에 저장돼 새로고침 후에도 유지.
- 상단 파형은 실제 소리(녹음·재생)를 실시간 표시, 음성 읽기 중에는 단어 경계에 맞춰 반응.

## 테스트
`node voice-maker/tests/regression.js` — PC·폰 폭, 글 읽기 UI, 가짜 마이크 녹음, 프리셋 10종 WAV 저장·길이·숨소리 잡음, EQ 실시간 조절, 파일 불러오기, 마이크 거부 안내까지 40개 항목 확인.
`node voice-maker/tests/review-fixes.js` — 서비스 워커 캐시 범위, AI 중복 생성 방지, 생성 중 글 수정, 입력 중 글 보존, 한도 초과 문구, 줄 녹음 전환 11개 항목.
`node voice-maker/tests/narration.js` — 내레이션: 원고 나누기, 화자, 줄 녹음·복원, ElevenLabs(가짜 응답: 목록·남은 글자·생성·캐시·401·연결 실패), WAV·SRT 내보내기 26개 항목.
