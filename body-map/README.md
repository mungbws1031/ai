# 몸속 통증 지도 (body-map)

아픈 부위를 고르면 19개 부위·대표 원인 46가지를 몸속 애니메이션(정상 ↔ 아플 때)으로 보여주고,
원인별로 **진료과 · 의원→병원→종합병원→상급종합병원 단계별로 받을 수 있는 것 · 주요 검사/치료 기술과 장비**를 안내하는 교육용 단일 HTML 앱입니다.

- 실행: `index.html`을 브라우저로 열기 (빌드·서버 불필요, 폰트만 Google Fonts에서 로드)
- 데이터: `index.html` 안의 `REGIONS`, `C`(원인·진료 안내), `SCENES`(SVG 애니메이션)
- 내 근처 찾기: 동네 이름(또는 브라우저가 허용하면 현재 위치)으로 진료과·전문병원 검색 링크를 네이버 지도·카카오맵·구글 지도로 엽니다. 입력값은 브라우저 localStorage에만 저장됩니다. (Artifact 화면에서는 위치 권한이 막혀 있어 동네 입력 방식으로 동작)
- 해부 일러스트: `img/<원인id>.jpg`(아플 때)와 `img/<원인id>-normal.jpg`(정상) 각 35장, 총 70장(초기 35개 질환)은 GPT 이미지 모델(Magnific, GPT 2.5)로 생성한 교육용 참고 그림입니다. "움직이는 그림" 탭에서 기존 SVG 애니메이션(정상↔아플 때)도 볼 수 있습니다.
- 새로 추가한 11개 질환 중 10개(눈·귀·턱·팔꿈치·고관절·대상포진·전립선염)의 정상/아플 때 그림 20장은 Figma 이미지 생성(gpt-image-2.5-flare)으로 만들었습니다. 발목 염좌는 아직 그림을 가져오지 못해 움직이는 그림으로 표시됩니다(`NO_IMG`).
- 새 그림 생성 규칙: 지금 있는 70장은 그대로 두고, **앞으로 새로 만드는 그림은 OpenAI GPT Image 2(`gpt-image-2`)로 직접 생성**합니다(Magnific 사용 안 함). 환경에 `OPENAI_API_KEY`와 `api.openai.com` 네트워크 허용이 필요합니다.
- 진단 도구가 아닙니다. 특정 병원을 추천하지 않으며, 병원별 장비는 건강보험심사평가원 병원 찾기에서 확인하도록 안내합니다.
