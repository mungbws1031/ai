# PM 역량 맵

PM에게 필요한 역량 16개를 6개 분야(고객·데이터·전략·실행·소통·기술) 맵으로 보여 주는 설치형 **PWA**입니다.
새로운 일이 생기면 맵에 넣어 필요한 역량을 하이라이트하고, 일이 끝나면 그 역량으로 퀴즈를 풀어 제대로 이해했는지 확인합니다.
빌드 과정 없는 단일 HTML 앱이고, 한 번 연 뒤에는 오프라인에서도 동작합니다.

## 실행 / 설치
서비스 워커(오프라인·설치)는 `http(s)`로 서빙해야 동작합니다.

```bash
cd pm-map
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

- **데스크톱(Chrome/Edge)**: 주소창의 설치 아이콘 또는 화면 오른쪽 위 **앱 설치** 버튼
- **안드로이드(Chrome)**: 메뉴 → "앱 설치" / "홈 화면에 추가"
- **iOS(Safari)**: 공유 → "홈 화면에 추가"

미리보기만 하려면 `index.html`을 더블클릭해도 됩니다(이때는 오프라인 캐시와 설치가 꺼집니다).
`pm-map/` 폴더를 GitHub Pages, Netlify, Vercel 같은 정적 호스팅에 그대로 올려도 됩니다.

## 사용 흐름
1. **수준 기록**: 타일을 눌러 내 수준을 0~4(모름 → 가르칠 수 있음)로 고릅니다. 수준이 높을수록 타일이 진한 주황색이 됩니다.
2. **이번 일 넣기**: 예시 업무 5개 중 하나를 고르거나 직접 적습니다. 필요한 역량은 파란 테두리로, 그중 수준 2 미만은 "보강"으로 표시됩니다.
3. **AI 프롬프트 복사**: 내 맵, 현재 수준, 이번 일을 담은 프롬프트를 복사해 Claude 등에 붙여넣으면 역량 분석과 맞춤 퀴즈를 받을 수 있습니다.
4. **일 끝 · 퀴즈 풀기**: 하이라이트된 역량마다 상황형 문제가 1개씩 나오고 해설이 붙습니다. 틀린 역량에는 "복습" 표시가 남고, 다음에는 다른 문제가 나옵니다.

## 캐릭터 · 팀 · 퀘스트
- **내 캐릭터**: 16개 역량 수준으로 캐릭터가 만들어집니다. 가장 높은 분야가 직업(고객→탐험가, 데이터→분석가, 전략→전략가, 실행→해결사, 소통→조율자, 기술→설계자)이 되고, 두 분야가 비슷하면 혼합형(예: 분석가 × 전략가)이 됩니다. 경험치는 역량 수준 1점당 5, 퀴즈 정답 1개당 3이고 20마다 레벨이 오릅니다. 이름·닉네임은 PM이 직접 정합니다.
- **팀 · 퀘스트**(팀장용): 팀원이 보낸 백업 파일을 여러 개 한 번에 추가하면 팀 캐릭터 카드와 PM × 16역량 표가 생깁니다. 일을 고르거나 적으면 필요 역량 평균으로 **적임자**와 **성장 기회**(멘토 제안 포함)를 추천합니다.
- **퀘스트 링크**: 추천 목록에서 "퀘스트 링크"를 누르면 그 PM에게 보낼 메시지(링크 포함)가 복사됩니다. PM이 링크를 열면 역량 맵에 그 일이 바로 표시됩니다.
- 본인이 백업을 보낸 사람만 팀에 나타납니다(opt-in). "예시 팀 보기"는 체험용 예시 데이터입니다.

## 데이터
- 수준·퀴즈 기록·마지막 업무는 브라우저 `localStorage`(`pm-competency-map-v1`)에만 저장됩니다. 서버로 보내는 데이터는 없습니다.
- **백업 저장**으로 JSON 파일을 내려받고, 다른 기기에서 **백업 불러오기**로 옮길 수 있습니다.
- **초기화**는 확인 후 수준과 퀴즈 기록을 모두 지웁니다.

## 구성
- `index.html` — 앱 본체(UI·데이터·로직 단일 파일). 역량은 `COMP`, 예시 업무는 `PRESETS` 배열에서 고칩니다.
- `manifest.webmanifest` — PWA 메타데이터
- `sw.js` — 오프라인 캐시 서비스 워커. 앱을 고치면 `CACHE` 버전을 올려야 설치된 앱이 새 버전을 받습니다.
- `icon-192.png`, `icon-512.png` — 앱 아이콘. 저장소 루트에서 `python3 pm-map/gen_icons.py`로 다시 만듭니다.

## 한계
- 직접 적은 업무는 역량별 키워드로 매칭하는 단순한 방식입니다. 정확한 분석은 AI 프롬프트 기능을 쓰세요.
- 퀴즈는 역량당 2문제, 모두 32문제입니다.
