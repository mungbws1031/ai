# 티나 · 티 나게 정리

> **1시간을 정리해도 티가 안 나는 사람을 위한, 정리 임팩트 최적화 앱**

어수선한 공간을 **사진 한 장**으로 분석해, *눈에 보이는 정돈 효과가 가장 큰 순서대로* 할 일을 짜주고, **비포/애프터 티 점수**로 "티 나게 정리됐음"을 증명해주는 설치형 **PWA**입니다. (PRD v0.11 Phase-1 핵심 루프 구현)

핵심 차별점 = "버리는 앱"도 "수납하는 앱"도 아닌, **같은 시간에 더 티 나게 만드는 앱.**

## 실행 / 설치 (앱으로 쓰기)
PWA(서비스 워커)는 `http(s)`로 서빙해야 동작합니다. 폴더에서:

```bash
cd tina
python3 -m http.server 8000
# 휴대폰/브라우저에서 http://localhost:8000 접속 (카메라 쓰려면 같은 네트워크에서 접속)
```

- **안드로이드(Chrome)**: 메뉴 → "앱 설치" / "홈 화면에 추가"
- **iOS(Safari)**: 공유 → "홈 화면에 추가"
- **데스크톱(Chrome/Edge)**: 주소창 오른쪽 설치 아이콘

> 빠르게 미리보기만 하려면 `index.html`을 더블클릭해도 됩니다(이 경우 서비스워커/설치는 비활성). 카메라 대신 갤러리 사진 업로드로 테스트할 수 있어요.

## 핵심 루프 (Phase 1 MVP)
**비포 사진 → AI 티 점수 분석 → 임팩트 순 미션 → 애프터 재채점 → 비포/애프터 델타 리빌.** 이 한 바퀴로 "증명 경험"이라는 핵심 가설을 검증합니다.

1. **비포 촬영/업로드** — 카메라 또는 갤러리에서 공간 1장.
2. **티 점수 분석 + 정돈 레벨** — 6차원 루브릭으로 0~100 채점 → 5단계 날씨 레벨(🌫️안개주의보 → ☀️쾌청)로 번역, 티 큰 영역 Top 3~4 식별.
3. **임팩트 순 미션 플랜** — 효과 큰 순서로 정렬된, 시간 박스된 작은 미션. 체크/스킵 자유(비난 없음), 미션별 타이머.
4. **애프터 + 재채점 + 리빌** — 레벨 점프(헤드라인) · 점수 델타 · 효자(MVP) 미션 · 시간 효율. 총점이 덜 올라도 *오른 차원 하나는 반드시 칭찬* + "한 방 더" 미션 1개 제안.

## 기능
- **6.1 티 점수 루브릭** — 평면 비움(30%)·바닥 가시성(20%)·라인 정렬(15%)·시각 밀도(15%)·담김 상태(12%)·색 노이즈(8%)의 가중 합산.
- **6.4 정돈 레벨(날씨 톤)** — 차가운 숫자를 감정이 실리는 5단계로 번역. 낮은 단계도 "넌 글렀어"가 아니라 "여기서 시작"으로 읽히게.
- **6.2 티 메이커 원칙 미션** — ① 평면부터 비우기 ② 바닥 드러내기 ③ 분류 말고 담기 ④ 라인 맞추기 ⑤ 히어로 존 하나. 차원별 결핍 크기로 예상 임팩트(+점수)를 매겨 정렬.
- **6.3 반-churn 결정 헬퍼** — "이거 어디 두지?" 모달: 지금 쓰는 것 / 나중 상자 / 보류 봉투. *세부 분류 금지* — 통에 담기만 해도 점수는 오릅니다.
- **스피드런 모드** — "게스트 임박" 임팩트 액션만 압축(2개·짧은 타임박스).
- **미션별 타이머** — 카운트다운 + 완료음.
- **히스토리 / 관대한 스트릭** — 비포애프터·점수 추이, 일 연속·이번 주 세션·누적 티 점수. 쉼 허용.
- **오프라인 동작** — 설치 후 비행기 모드에서도 온디바이스 분석으로 작동.

## 채점 엔진 (2가지)
설정(⚙️)에서 선택합니다.

1. **온디바이스 추정 (기본 · 오프라인 · 서버 전송 없음)**
   - 브라우저 Canvas로 사진의 픽셀을 분석해 6차원을 **결정론적으로** 근사합니다(Sobel 엣지 밀도·블록 분산 평활도·바닥 영역 평활도·엣지 방향 정렬도·색 히스토그램 엔트로피/분절도).
   - 집 내부 사진이 **기기 밖으로 나가지 않습니다.** (PRD §10 프라이버시 오픈 이슈에 대한 기본 답)
   - 같은 사진은 항상 같은 점수 → 비포/애프터 편차 최소화(§9 일관성).

2. **Claude 비전 API (선택 · 정확도↑ · 내 키 필요)**
   - 6.1 루브릭을 시스템 프롬프트로 주입하고 **구조화 JSON 출력**(`output_config.format`)으로 강제해 일관 채점.
   - 브라우저에서 Anthropic API(`claude-opus-4-8` 기본 / `claude-sonnet-4-6` 선택)를 **직접 호출**합니다. 키는 이 기기 `localStorage`에만 저장됩니다.
   - ⚠️ 이 모드에서는 사진이 Anthropic 서버로 전송됩니다. 민감하면 온디바이스를 쓰세요. 실패 시 자동으로 온디바이스로 대체됩니다.

## 구성
- `index.html` — 앱 본체(UI·로직·온디바이스 분석·Claude 연동, 단일 파일)
- `manifest.webmanifest` — PWA 메타데이터
- `sw.js` — 오프라인 캐시 서비스 워커(교차 출처 API 호출은 캐시하지 않음)
- `icon-192.png`, `icon-512.png` — 앱 아이콘 (`gen_icons.py`로 생성, 순수 stdlib)

## 정직성 메모
온디바이스 티 점수는 "사람이 느끼는 정돈감"을 근사하는 **단순화 휴리스틱 모델**입니다. 물리적 정밀 측정이 아니며, 절대 점수보다 **비포→애프터 변화(델타)**에 강점이 있습니다. 절대값 캘리브레이션은 라벨링된 비포/애프터 셋으로 추후 보정 대상입니다(PRD §10).
