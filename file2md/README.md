# 파일 → 마크다운 (file2md)

거의 모든 파일을 **브라우저 안에서** 마크다운(`.md`)으로 바꾸는 단일 HTML 웹앱입니다.
파일은 서버로 올라가지 않고, 변환은 전부 내 컴퓨터에서 이뤄집니다.

## 실행

`index.html`을 더블클릭해서 열면 끝입니다. (서버 불필요)
변환 라이브러리는 해당 형식을 처음 열 때 CDN에서 불러오므로 **인터넷 연결이 필요**합니다.

```bash
# 원하면 로컬 서버로 열어도 됩니다
cd file2md && python3 -m http.server 8000
```

## 지원 형식

| 형식 | 변환 내용 |
| --- | --- |
| PDF | 글자 위치로 줄·문단 복원, 큰 글씨 → 제목, 글머리표 → 목록, 쪽 구분 주석. 스캔본은 OCR 옵션으로 읽기 |
| Word `.docx` | 제목·굵게·기울임·목록·표·링크 (mammoth → Turndown) |
| Excel `.xlsx .xls .xlsb .ods` | 시트마다 `## 시트명` + 표 |
| PowerPoint `.pptx` | 슬라이드별 제목·글머리(들여쓰기 단계)·표·발표자 노트 |
| 한글 `.hwpx` | 문단과 표 (예전 `.hwp`는 한글에서 HWPX/DOCX로 저장 후 사용) |
| ODT/ODP, EPUB | 제목·문단·목록·표 / 책 순서(spine)대로 장 연결 |
| HTML, RTF, 이메일 `.eml` | HTML은 그대로 변환, RTF는 한글(CP949) 포함 텍스트, 메일은 머리글 표 + 본문 + 첨부 목록 |
| CSV/TSV, JSON | 구분자 자동 감지 표 / 객체 배열은 표 + 원본 코드 블록 |
| 주피터 `.ipynb` | 마크다운 셀 + 코드 셀 + 텍스트 출력 |
| ZIP | 안의 파일 목록 + 각 파일을 하나씩 변환 |
| 이미지 | 정보 표 + 이미지 링크(옵션: 본문에 내장), OCR 옵션으로 글자 추출(한국어+영어) |
| 오디오·영상 | 길이·해상도 등 정보만 |
| 코드·텍스트 | 언어 표시된 코드 블록. 한국어 EUC-KR 텍스트도 자동 인식 |

모르는 형식이라도 텍스트이면 코드 블록으로, 바이너리면 파일 정보만 남깁니다.

## 기능

- 여러 파일 한 번에(끌어다 놓기·선택·붙여넣기), 차례로 변환
- 결과를 바로 **고쳐 쓰기**, 미리보기, 복사, `.md` 내려받기
- **전체 ZIP**(파일마다 .md) / **하나로 합치기**(한 개의 .md)

## 쓰는 라이브러리 (필요할 때만 로딩)

pdf.js 3.11.174 · mammoth 1.6.0 · Turndown 7.1.2 (+gfm) · SheetJS 0.18.5 · JSZip 3.10.1 · marked 12 + DOMPurify 3 · tesseract.js 5.1.0

## 한계

- 복잡한 레이아웃(다단, 표 안의 표, 텍스트 상자 배치)은 단순해집니다.
- PDF 표는 줄 단위 텍스트로 나옵니다(표 구조 복원 없음).
- OCR은 처음 실행 때 언어 데이터(수십 MB)를 내려받아 느립니다.
