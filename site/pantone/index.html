팬톤 컬러 매칭

코드·이름으로 색상을 찾거나, HEX 값을 입력해 가장 가까운 팬톤 색상을 계산합니다.

색상 매칭

색상을 선택하면 HEX / RGB / CMYK 값과 인접 색상이 여기에 표시됩니다.

● 표시가 있는 색상은 팬톤·RAL이 실제로 고유 이름을 붙인 색입니다. 마커가 없는 색상도 전부 실제 팬톤 코드와 색상값이며, 다만 이름이 따로 없어 색조·명도로 자동 설명명을 붙였을 뿐입니다.

PANTONE Solid Coated 3,219색은 Adobe가 라이선스해 배포하는 공식 컬러북의 Lab 색상값을 표준 변환식(Lab→XYZ(D50)→Bradford 색순응→XYZ(D65)→sRGB)으로 직접 계산해 넣었습니다 — 특정 색만 골라 웹에서 검색한 값이 아니라 전체 라이브러리를 동일한 파이프라인으로 일괄 변환했기 때문에 값끼리 서로 어긋나지 않습니다. 여기에 팬톤 컬러 오브 더 이어로 유명한 TCX 6종(Marsala·Ultra Violet 등, 개별 출처 대조 완료)을 더했습니다.

제품 도색(플라스틱 사출·금속 도장) 용도라면 PANTONE보다 RAL Classic을 실제 발주 기준으로 사용하는 경우가 많습니다 — 상단에서 "RAL Classic (도색)" 컬렉션을 선택한 뒤 HEX를 입력하면 가장 가까운 RAL 코드를 찾아줍니다. 메탈릭 색상은 잉크의 금속 안료 특성상 화면(sRGB)으로는 실제 광택·반사를 재현할 수 없다는 점도 참고하세요.

모든 값은 모니터·브라우저 설정 및 Lab→sRGB 변환 방식에 따라 실제 인쇄물과 차이가 있을 수 있으며, 실물 색상 승인에는 반드시 공식 PANTONE/RAL 컬러 가이드 실물 대조를 거치세요. PANTONE®은 Pantone LLC의, RAL®은 RAL gGmbH의 등록 상표입니다.
