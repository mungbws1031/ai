# 한 끼의 소화 여정 (digestion-sim)

먹은 음식이 입 → 위 → 소장 → 대장 → 직장을 지나며 분해·흡수되고 변으로 나가는 과정을
72시간 동안 시뮬레이션하는 단일 파일 웹페이지입니다. 빌드 없이 `index.html`을 브라우저로 열면 됩니다.

## 기능
- 한 끼 또는 하루 세 끼 + 간식(최대 3개) 입력, 예시 식단·간식, 영양소 슬라이더
- 해부도 위에서 음식 이동, 간문맥·림프관·단쇄지방산 흡수 경로 애니메이션
- 소화 시간표(장기별 띠 그래프 + 이정표), 위치·흡수 속도 그래프
- 변이 만들어지는 과정(구간별 수분·세균·브리스톨 척도)과 변 상태 예측(정상/변비 주의/위험/묽은 변)
- 식사 시각, 배변 시각·횟수, 하루 물 섭취량, 활동량 설정(브라우저에 저장)
- 음식 사진으로 영양성분 추정: claude.ai 아티팩트로 열었을 때만 동작(`sample` 이미지 기능 사용)
  - 여러 장을 한꺼번에 올리면 하루 모드에서는 사진마다 간식 카드가 하나씩 생기고(파일 시각을 간식 시각으로 사용, 최대 3개), 한 끼 모드에서는 합쳐서 한 끼로 계산합니다.

## 모델
구획(compartment) 모델입니다. 위는 끼니별 반감기(지방·단백질이 많을수록 길어짐), 소장은 3구간,
대장은 3구간 + 직장으로 나누고, 교과서 평균값으로 정한 소화율·발효율·수분 비율을 씁니다.
상수는 `index.html` 스크립트 상단(`EAT_MIN`, `SEC`, `SCFA_YIELD`, `SI_ESC`, `CO_ESC`, `CO_RATIO` 등)에 모여 있습니다.

교육용 근사치이며 진단이나 식단 처방에 쓰면 안 됩니다. 근거 자료는 페이지 하단에 있습니다.
