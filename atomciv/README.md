# 원자에서 문명까지 (atomciv)

초등학생이 태블릿에서 혼자 하는 과학 게임. 원자를 손잡게 해서 분자를 만들고,
분자·자연 재료로 발명품을 만들어 석기시대 → 청동기시대 → 철기시대 → 산업시대 → 전기시대 → 정보시대 → 현대까지 문명을 키운다.

설계: `docs/superpowers/specs/2026-11-18-atomciv-design.md` · 계획: `docs/superpowers/plans/2026-11-18-atomciv.md`

## 실행

- 그냥 `index.html`을 브라우저로 열면 된다 (인터넷 필요 없음).
- 태블릿에 "앱처럼" 설치하려면 정적 서버(https)로 올린 뒤 브라우저 메뉴에서 **홈 화면에 추가**.
  예: `python3 -m http.server 8000` 후 같은 와이파이의 태블릿에서 접속 (서비스워커는 https/localhost에서만 동작).
- 진행 상황은 기기 브라우저(localStorage `atomciv.v1`)에 저장된다. 저장이 막혀도 게임은 동작한다.

## 놀이 방법

- **미션**: 목표를 하나씩. 막히면 💡 힌트 → 필요한 재료가 반짝인다.
- **실험실**: 원자 서랍을 눌러 실험대에 올리고, 원자를 끌어 다른 원자에 대면 손을 잡는다.
  같은 쌍을 한 번 더 대면 이중결합, 또 대면 삼중결합. 원자를 서랍으로 끌어다 놓으면 버린다.
- **섞는 그릇 + 합치기**: 실험대 정가운데의 🥣 그릇으로 재료를 끌어오거나 눌러서 넣고 ✨합치기 (최대 6개).
  그릇의 재료를 밖으로 끌어내면 빠진다. 열이 필요한 레시피는 발명한 🔥 불을 재료처럼 그릇에 함께 넣는다.
  재료로 쓰이는 분자(물, 모래, 소금)는 만들면 그릇으로 바로 들어간다. 첫 재료 미션에서 사용법 카드가 한 번 나온다.
- **도감**: 만든 분자와 발명.
- **영토 지도**: 육각 타일 섬. 🏛️ 수도에서 시작해 발명할 때마다 그 땅과 주변이 우리 영토가 되고 국경선이 넓어진다.
  영토 바로 바깥 한 칸만 보이고 나머지는 안개. 발명 아이콘을 누르면 설명 카드.
- **💾 저장 / 불러오기**: 진행 상황을 파일로 저장해 다른 기기로 옮길 수 있다 (기기 안에는 자동 저장).

## 과학 규칙과 단순화 (아이에게 거짓을 가르치지 않기 위한 기록)

- 손 개수 = 원자가: H 1, O 2, N 3, C 4, Cl 1, Na 1, Si 4, F 1, S 2, Mg 2, K 1, Ca 2, P 3, I 1, He 0, Ne 0. 모든 손이 잡히면 분자 완성.
  손이 0개인 헬륨·네온(비활성 기체)은 혼자서도 완성이다. 서랍의 원자는 원자번호 순서로 놓는다.
- 금속(Na, Mg, K, Ca)과 비금속(Cl, F, O, I)의 결합은 이온결합으로 그린다 (점선, 전하 표시).
  전하 숫자는 그 원자가 이온결합으로 실제 주고받은 전자 수다 (MgO의 O는 2−, NaOH의 O는 1−, CaCl₂의 Ca는 2+).
  수산화나트륨·탄산칼슘처럼 이온결합과 공유결합이 섞인 물질도 같은 방식으로 표시한다.
- 분자는 분자식으로 판정한다. 에탄올(C₂H₆O)처럼 같은 분자식에 모양만 다른 분자(이성질체)는 구분하지 않는다.
  규칙에 맞지만 목록에 없는 분자(예: H₂O₃)는 "아직 이름 모르는 분자"로 칭찬만 한다.
- 소금(NaCl)은 이온결합이라 "Na가 전자를 Cl에게 줘 버려서 끌어당긴다"로 설명한다.
  조작은 다른 결합과 같지만, 화면에서는 점선과 Na⁺ / Cl⁻ 전하 표시로 다르게 그린다.
- 일산화탄소(CO)는 넣지 않았다. 실제 CO는 손 규칙(원자가)만으로 설명되지 않기 때문.
- 모래는 이산화규소(SiO₂)로 단순화했다. 실제 SiO₂는 하나의 분자가 아니라 거대한 그물 구조다.
- 물질·발명 레시피(숯, 토기, 구리, 청동, 철, 유리 등)는 실제 과학·역사를 바탕으로 **설계한 조합표**다.
  물리 규칙이 자동으로 판정하는 것은 원자→분자 단계뿐이다.
