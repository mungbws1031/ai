# mold-quote — 금형 가상 견적

QDM·일반 양산·정밀 양산 금형의 **금형비**와 **개당 사출비**를 어림하는 단일 파일 웹앱입니다.
`index.html`을 브라우저로 열면 바로 쓸 수 있습니다. 서버나 빌드가 필요 없습니다.

## 입력
- 금형 방식: QDM(표준 베이스 + 인서트 교체 간이 금형) / 일반 양산(HP4A) / 정밀 양산(STAVAX)
- 제품 크기 L×W×H, 살두께, 형상 복잡도(1~5), 중량 직접 입력(선택)
- 소재: PP, ABS, PC/ABS, PC, POM, PA66 GF30, PBT GF30, PMMA, TPE/TPU (수지 단가 수정 가능)
- 캐비티 수, 캐비티당 슬라이드·리프터 수, 표면 처리, 콜드/핫 러너
- 총 생산 수량, 로트, 후가공비, 불량률

## 출력
- 금형비 항목별 내역(몰드베이스, 코어·캐비티, 슬라이드, 리프터, 핫러너, 부식, 설계, 시사출, 관리비)
- 개당 사출비 내역(수지비, 사출기 임률, 셋업 분담, 후가공, 관리비)
- 형체력 → 사출기 톤수, 사이클 타임, 제품·쇼트 중량, 시간당 생산량, 제작 기간
- 가동측 형판 평면도(캐비티 배열·슬라이드·냉각 라인·게이트)
- QDM과 일반 금형의 수량별 총비용 그래프와 손익 분기 수량
- QDM 제약(캐비티·슬라이드·크기·핫러너), 유리섬유 마모, 금형 수명 초과 경고

## 주의
계수는 2026년 국내 중소 금형·사출 업체 시세를 어림한 **휴리스틱**이며 실제 견적이 아닙니다.
도면, 업체, 시기에 따라 ±30% 이상 차이가 날 수 있습니다. 계산식은 화면의 "계산 기준"과 `index.html`의 `compute()`에 있습니다.
